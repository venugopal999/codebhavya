📊 10. Arrays

🎓 Concept-First Explanation

This lesson is organized in the same order a faculty member would normally teach it: meaning → purpose → syntax/model → internal working → examples → common confusion → safe use. The guided examples from the earlier lesson are preserved afterward for reinforcement.

10.1 What an Array Is

An array is a fixed-size sequence of elements of the same type stored contiguously. The array type includes both the element type and the number of elements, for example int[5].

int marks[5];
marks
index:    0      1      2      3      4
        +------+------+------+------+------+
value   |      |      |      |      |      |
        +------+------+------+------+------+

10.2 Why Indexing Starts at 0

For an array expression a, the subscript expression a[i] is defined in terms of pointer arithmetic as *(a + i). Index 0 means zero elements away from the first element; index 1 means one element away.

a[i] ≡ *(a + i)

10.3 Declaration, Initialization and Partial Initialization

int a[5];
int b[5] = {10, 20, 30, 40, 50};
int c[]  = {1, 2, 3};
int d[5] = {1, 2}; /* remaining elements initialized to zero */

The array bound must be valid for the form being used. When an initializer supplies fewer values than the declared fixed size, remaining elements are initialized as required by aggregate initialization rules.

10.4 Array Bounds — C Does Not Automatically Check Them

int a[5] = {0};
a[5] = 10; /* out of bounds: valid indices are 0..4 */

Accessing outside the array object is undefined behavior. The fact that adjacent memory appears to hold another variable does not make an out-of-bounds access legal.

10.5 Traversal — The Foundation of Array Algorithms

for (size_t i = 0; i < 5; i++)
{
    printf("a[%zu] = %d\n", i, a[i]);
}

Most beginner array algorithms are variations of one traversal: maintain an accumulator, current best value, count, search state or transformation while visiting elements.

10.6 Aggregation: Sum, Average, Minimum and Maximum

long long sum = 0;
int min = a[0];
int max = a[0];

for (size_t i = 0; i < n; i++)
{
    sum += a[i];
    if (a[i] < min) min = a[i];
    if (a[i] > max) max = a[i];
}

double average = (double)sum / n;
Important

Minimum/maximum initialization with a[0] requires n > 0. Empty input needs a separate design decision.

10.7 Linear Search

size_t i;
for (i = 0; i < n; i++)
{
    if (a[i] == target)
        break;
}

if (i < n)
    printf("Found at %zu\n", i);

Linear search needs no sorted order and examines at most n elements. Its time complexity is O(n).

10.8 Binary Search — Why Sorting Is Required

Binary search uses the ordering property to discard half of the remaining search range. Without sorted data, seeing that the middle element is smaller than the target tells you nothing about which half contains the target.

size_t low = 0, high = n;
while (low < high)
{
    size_t mid = low + (high - low) / 2;
    if (a[mid] < target)
        low = mid + 1;
    else
        high = mid;
}

if (low < n && a[low] == target)
    printf("Found at %zu\n", low);
sorted:  3  8  12  19  24  31  45
          L          M           H
compare target with middle → keep only possible half

10.9 Bubble Sort — Repeated Adjacent Exchanges

Bubble sort compares adjacent elements and swaps them when out of order. After one full pass, an extreme value moves toward its final end position.

for (size_t pass = 0; pass + 1 < n; pass++)
{
    int swapped = 0;
    for (size_t j = 0; j + 1 < n - pass; j++)
    {
        if (a[j] > a[j + 1])
        {
            int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            swapped = 1;
        }
    }
    if (!swapped) break;
}

10.10 Selection Sort — Select the Smallest Remaining Element

for (size_t i = 0; i + 1 < n; i++)
{
    size_t minIndex = i;
    for (size_t j = i + 1; j < n; j++)
        if (a[j] < a[minIndex])
            minIndex = j;

    int t = a[i]; a[i] = a[minIndex]; a[minIndex] = t;
}

The left portion becomes sorted one position at a time. Selection sort performs O(n²) comparisons and comparatively few swaps.

10.11 Insertion Sort — Grow a Sorted Prefix

for (size_t i = 1; i < n; i++)
{
    int key = a[i];
    size_t j = i;
    while (j > 0 && a[j - 1] > key)
    {
        a[j] = a[j - 1];
        j--;
    }
    a[j] = key;
}

Before iteration i, elements 0..i-1 are treated as sorted. The current key is inserted into its correct position within that prefix.

10.13 Two-Dimensional Arrays

int m[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

This is an array of 2 elements, where each element is itself an array of 3 int. In row-major layout, each complete row array is stored contiguously before the next row.

m[row][column]

10.14 Traversing a Matrix

for (size_t r = 0; r < rows; r++)
{
    for (size_t c = 0; c < cols; c++)
        printf("%d ", m[r][c]);
    putchar('\n');
}

The outer loop selects a row; the inner loop visits columns in that row. Reversing the loop order changes traversal order and may affect cache behavior in larger programs.

10.15 Matrix Addition and Subtraction

Matrices can be added or subtracted only when corresponding dimensions match. Each result element is computed independently from the same row/column position.

C[r][c] = A[r][c] ± B[r][c]

10.16 Matrix Transpose

The transpose exchanges rows and columns. If A has dimensions R × C, then its transpose has dimensions C × R.

T[c][r] = A[r][c]
A = 1 2 3      T = 1 4
    4 5 6          2 5
                     3 6

10.17 Matrix Multiplication — Understand the Dimension Rule First

If A is R × K and B is K × C, then A×B is defined and the result is R × C. The inner dimension K must match.

result[r][c] = Σ A[r][k] * B[k][c]
for (size_t r = 0; r < R; r++)
    for (size_t c = 0; c < C; c++)
    {
        result[r][c] = 0;
        for (size_t k = 0; k < K; k++)
            result[r][c] += A[r][k] * B[k][c];
    }
Why three loops?

One loop chooses the output row, one chooses the output column, and the innermost loop computes the dot product across the shared dimension.

10.18 Passing Arrays to Functions

void printArray(const int a[], size_t n);
void printMatrix(size_t rows, size_t cols, const int a[rows][cols]);

In a function parameter declaration, an array parameter is adjusted to a pointer parameter. The function therefore does not automatically know the element count; pass dimensions explicitly or use another agreed protocol. For multidimensional arrays, later dimensions/shape information are needed so address calculations are meaningful.

10.19 Array-to-Pointer Conversion and sizeof Trap

int a[10];
size_t count_here = sizeof a / sizeof a[0];

void f(int a[])
{
    /* here a is adjusted to int *; sizeof a is pointer size */
}

The array-to-pointer conversion happens in most expressions, but not all. This is why the common element-count formula works where the actual array object is visible, but not inside a function that received an adjusted array parameter.

10.20 Variable Length Arrays — Know the Portability Caveat

Some C language versions/implementations support arrays whose bound is determined at runtime, such as int a[n];. Support and status vary by standard version and implementation, and large automatic arrays can exhaust stack-like storage. Dynamic allocation is often a more explicit choice for large/runtime-sized data.

10.21 Array Problem-Solving Checklist

  • What are valid indices?
  • Can the array be empty?
  • Is order important?
  • Does the algorithm modify the array or only read it?
  • Does a search require sorted data?
  • Are dimensions compatible for matrix operations?
  • Are sizes passed explicitly to functions?
  • Could accumulation overflow the chosen type?

🔍 Deeper understanding: Array objects, decay and bounds

An array is one object containing contiguous elements of one type. sizeof array / sizeof array[0] gives the element count only where array is still an actual array. In most expressions—and in a function parameter declaration—an array expression is converted to a pointer to its first element. The receiving function therefore needs the length separately.

void print_values(const int values[], size_t length)
{
    for (size_t i = 0; i < length; ++i)
        printf("%d\\n", values[i]);
}

C performs no automatic bounds check. Even forming or using an invalid element such as values[length] is outside the array and leads to undefined behaviour. A pointer may be formed one position past an array for comparison and loop termination, but that one-past pointer must never be dereferenced. Multidimensional arrays are stored row by row, and all dimensions except the first must be known when passed to an ordinary function parameter.

Common Array Mistakes

  • Forgetting that array indexing starts from 0.
  • Accessing an index outside the valid range.
  • Using i <= n instead of i < n while traversing.
  • Forgetting to initialize variables such as sum, count or maximum.
  • Using an incorrect loop limit.
  • Confusing array index with array value.
  • Forgetting to check special cases such as an empty or too-small input where applicable.
Reasoning trace:
caller array expression → conversion to pointer to first element → function receives pointer plus explicit length
📘 Standard and portability note

Variable-length arrays are optional in later C standards for some implementations; fixed-size arrays and dynamic allocation are more widely portable.

📊 Deep Dive — Arrays, Searching, Sorting and Matrices

Why Array Elements Are Fast to Access

Array elements occupy one contiguous sequence of memory. Conceptually, if a begins at address B, then element a[i] is located at an offset based on i and the size of one element:

address of a[i] = base address + i × sizeof(element)

C expresses the same relationship through pointers: &a[i] is equivalent to a + i, and a[i] is equivalent to *(a + i) when a has converted to a pointer expression.

Memory idea
int a[5] = {10, 20, 30, 40, 50};

index:     0      1      2      3      4
value:    10     20     30     40     50
memory: [____] [____] [____] [____] [____]
           ↑
        first element

Valid element indexes: 0 through 4
One-past position: a + 5  (may be formed, not dereferenced)

Binary Search — Why Sorting Is Required

Linear search can inspect values one by one. Binary search is faster on a sorted array because one comparison can discard roughly half of the remaining search interval.

Array:  3   8   12   17   25   31   44
Index:  0   1    2    3    4    5    6
Target: 25

low = 0, high = 6
mid = 3 → a[3] = 17
25 > 17 → discard indexes 0..3

low = 4, high = 6
mid = 5 → a[5] = 31
25 < 31 → discard indexes 5..6

low = 4, high = 4
mid = 4 → a[4] = 25 → found
int binary_search(const int a[], int n, int target)
{
    int low = 0;
    int high = n - 1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (a[mid] == target)
            return mid;
        if (a[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }

    return -1;
}
⚠️ Why can't binary search be used on an unsorted array?

If a[mid] < target, binary search assumes every element to the left is no larger than a[mid]. That conclusion depends on sorted order. Without it, discarding half the array is not logically valid.

Selection Sort — Select the Smallest Remaining Value

Selection sort divides the array into a sorted prefix and an unsorted remainder. For each position, find the smallest remaining element and place it there.

Start:        29  10  14  37  13
Pass 1:       10  29  14  37  13
Pass 2:       10  13  14  37  29
Pass 3:       10  13  14  37  29
Pass 4:       10  13  14  29  37
for (int i = 0; i < n - 1; ++i) {
    int min_index = i;

    for (int j = i + 1; j < n; ++j) {
        if (a[j] < a[min_index])
            min_index = j;
    }

    if (min_index != i) {
        int temp = a[i];
        a[i] = a[min_index];
        a[min_index] = temp;
    }
}

Insertion Sort — Insert Each Value into the Sorted Prefix

Insertion sort behaves like arranging playing cards in your hand. Treat the left part as sorted, take the next value as the key, shift larger values right, and insert the key into the gap.

Start:        7   4   5   2
Insert 4:     4   7   5   2
Insert 5:     4   5   7   2
Insert 2:     2   4   5   7
for (int i = 1; i < n; ++i) {
    int key = a[i];
    int j = i - 1;

    while (j >= 0 && a[j] > key) {
        a[j + 1] = a[j];
        --j;
    }

    a[j + 1] = key;
}

Matrix Transpose

The transpose swaps rows with columns. If matrix A has dimensions r × c, its transpose has dimensions c × r and:

T[j][i] = A[i][j]
for (int i = 0; i < rows; ++i)
    for (int j = 0; j < cols; ++j)
        transpose[j][i] = a[i][j];

Matrix Multiplication — The Dimension Rule Matters

If A is r1 × c1 and B is r2 × c2, multiplication A × B is valid only when c1 == r2. The result has dimensions r1 × c2.

C[i][j] = Σ A[i][k] × B[k][j]
for (int i = 0; i < r1; ++i) {
    for (int j = 0; j < c2; ++j) {
        c[i][j] = 0;
        for (int k = 0; k < c1; ++k)
            c[i][j] += a[i][k] * b[k][j];
    }
}
💡 Why three loops?

The first chooses a result row, the second chooses a result column, and the third forms the dot product of one row of A with one column of B.

Passing a 2D Array to a Function

For an ordinary multidimensional array parameter, the compiler needs enough dimension information to calculate where each row begins.

void print_matrix(int rows, int cols, int a[rows][cols])
{
    for (int i = 0; i < rows; ++i)
        for (int j = 0; j < cols; ++j)
            printf("%d ", a[i][j]);
}

This form uses variable-length array parameter syntax supported by implementations that provide VLAs. A fixed known column bound is another common teaching form.

INTERVIEW PREPARATION

🎤 Arrays — Interview Questions







1.
Why do C arrays use zero-based indexing?





                Array indexing is defined relative to the base address, so arr[0] refers to the first element at offset zero.
            







2.
What happens if you access an array outside its valid index range?





                C does not perform automatic bounds checking. Accessing outside the valid array range causes undefined behavior.
            







3.
What is array traversal?





                Array traversal means visiting the elements one by one, usually from index 0 to index n - 1.
            







4.
What is the difference between arr[i] and &arr[i]?





                arr[i] is the value of the element, while &arr[i] is the address of that element.
            







5.
How is a two-dimensional array typically stored in C?





                A normal C two-dimensional array is stored in row-major order: the elements of each row are contiguous before the next row.
            







6.
Why is linear search called linear?





                Because in the worst case it examines array elements one after another, so the work grows linearly with the number of elements.
            







7.
Why should maximum and minimum usually be initialized from arr[0]?





                Using arr[0] works correctly even when all array values are negative, unlike arbitrary initial values such as 0.
            







8.
What is the difference between reversing an array while printing and reversing it in place?





                Reverse printing leaves the stored array unchanged. In-place reversal swaps elements so the array itself is modified.
            









PLACEMENT TIPS

💡 Arrays — Placement Tips


    

  • Always identify the valid index range first: 0 to n - 1.
    • 

  • For maximum/minimum problems, initialize from an actual array element rather than an arbitrary constant.
    • 

  • For search questions, decide whether the array is sorted before choosing between linear search and more advanced techniques.
    • 

  • For duplicate/frequency questions, carefully separate value, position, and frequency.
    • 

  • For matrix questions, track row index i and column index j separately.
    • 

  • When using nested loops, estimate the total number of comparisons because this determines time complexity.
    •
