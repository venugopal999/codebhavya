➕ 6. Operators

🎓 Concept-First Explanation

This lesson is organized in the same order a faculty member would normally teach it: meaning → purpose → syntax/model → internal working → examples → common confusion → safe use. The guided examples from the earlier lesson are preserved afterward for reinforcement.

6.1 What an Operator Does

An operator tells C to perform an operation on one or more operands and produce a result or side effect. Understanding an operator requires four questions: what operands it accepts, what result it produces, whether it changes an object, and when/how its operands are evaluated.

By number of operandsExamples
Unary-x, !x, ~x, ++x
Binarya+b, a<b, a&b
Conditional/ternarycondition ? a : b

6.3 Relational and Equality Operators

Relational/equality expressions compare values and produce an int result: 1 for true and 0 for false.

CategoryOperators
Relational< <= > >=
Equality== !=
Classic confusion

= performs assignment. == compares for equality. if (x = 5) assigns 5 to x and then tests the resulting nonzero value; it is not an equality test.

6.4 Logical Operators and Truth in C

For scalar conditions, zero is treated as false and nonzero as true. Logical operators return 0 or 1.

OperatorMeaning
&&logical AND
||logical OR
!logical NOT
if (age >= 18 && age <= 60)
    printf("Eligible\n");

6.5 Short-Circuit Evaluation — A Semantic Guarantee

For &&, if the left operand is false, the right operand is not evaluated. For ||, if the left operand is true, the right operand is not evaluated.

if (x != 0 && 100 / x > 5)
{
    /* division is attempted only when x != 0 */
}
Why it matters

Short-circuiting is not merely an optimization. Programs commonly use it to guard an operation that would otherwise be invalid.

6.6 Assignment and Compound Assignment

x = 10;
x += 5;   /* conceptually x = x + 5, with important evaluation/conversion details */
x *= 2;

An assignment expression stores a converted value in a modifiable lvalue and also has a value. Compound assignment evaluates the left operand only once, which can matter when the left side is more complex than a simple variable.

6.7 Increment and Decrement: Prefix vs Postfix

int a = 5;
int p = ++a;   /* a becomes 6; expression value is 6 */

a = 5;
int q = a++;   /* expression value is 5; a becomes 6 */
FormChangeExpression value
++aincrement before value is producednew value
a++value is produced, then increment side effect is completed as requiredold value
Do not create puzzle expressions

Expressions that modify the same object multiple times without the required sequencing can have undefined behavior. Split updates into clear statements.

6.8 Conditional Operator ?: — An Expression, Not an if Statement

int max = (a > b) ? a : b;

The first operand is evaluated as a condition. Exactly one of the second or third operands is evaluated. Because the operator forms an expression, its result can be assigned, returned or embedded in a larger expression when readability remains good.

6.9 Bitwise Operators — Work on Integer Bit Patterns

Bitwise operators operate on integer operands after the language’s integer promotions/conversions. Unlike logical operators, they manipulate corresponding bits rather than reducing operands to true/false.

OperatorNameCore rule
&Bitwise ANDResult bit 1 only when both input bits are 1.
|Bitwise ORResult bit 1 when either input bit is 1.
^Bitwise XORResult bit 1 when input bits differ.
~Bitwise complementFlips every bit of the promoted operand.
<<Left shiftMoves bit pattern left subject to C shift rules.
>>Right shiftMoves bit pattern right subject to signedness/value rules.

6.12 Bitwise XOR ^ — Toggle Selected Bits

ABA ^ B
000

  0101  (5)

XOR with a mask toggles exactly the mask-selected bits: 0 becomes 1 and 1 becomes 0. XOR is also useful in parity and “unique element” style problems.

6.13 Bitwise Complement ~ — Flip Every Bit, Not the Truth Value

~ first works on the promoted integer operand and flips every bit. A small 8-bit drawing is only a visual aid; an actual int may have more bits.

8-bit teaching view
5   = 00000101
~5  = 11111010
int x = 5;
printf("%d\n", ~x);

On the overwhelmingly common two’s-complement representation, the result is -6, matching the identity ~x == -(x + 1). The standard’s exact signed representation rules depend on the targeted C version, so bit-mask work is usually clearest with unsigned types.

ExpressionMeaning
!5logical NOT: 5 is true, so result is 0
~5bitwise complement: flip every bit of the promoted integer value

6.14 Left Shift <<

5        = 00000101
5 << 1   = 00001010  -> 10
5 << 2   = 00010100  -> 20

For unsigned values and valid shift counts, left shift moves bits toward more significant positions, filling low-order positions with zeros. Bits shifted out are discarded. Do not memorize “left shift always multiplies by 2” without the range/definedness conditions.

6.15 Right Shift >>

20       = 00010100
20 >> 1  = 00001010  -> 10
20 >> 2  = 00000101  -> 5

For unsigned operands, right shift is well behaved as a logical shift. For signed negative values, the exact result has historically been implementation-defined in common C versions, so unsigned types are preferable when the intent is bit manipulation.

6.16 Logical vs Bitwise — Similar Symbols, Different Questions

LogicalBitwiseDifference
&&&truth test vs bit-by-bit AND
|||truth test vs bit-by-bit OR
!~reverse truth vs flip all bits

Logical && and || short-circuit. Bitwise & and | evaluate both operands and combine integer bit patterns.

6.18 Operator Safety Checklist

  • Check operand types before assuming arithmetic behavior.
  • Distinguish assignment = from equality ==.
  • Do not divide or take remainder by zero.
  • Use short-circuit conditions to guard unsafe operations.
  • Prefer unsigned types for deliberate bit manipulation.
  • Validate shift counts and avoid relying on signed-negative shift behavior.
  • Avoid expressions that modify the same scalar object multiple times without required sequencing.
  • Use parentheses for clarity even when precedence rules already determine grouping.

1. What is the result of 10 % 3?
Correct Answer: B

The modulus operator % gives the remainder of integer division. 10 divided by 3 leaves a remainder of 1.

2. Which operator is used for equality comparison?
Correct Answer: B

== compares two values for equality. The single = operator performs assignment.

3. What is the result of 5 / 2 when both operands are integers?
Correct Answer: C

Because both operands are int, integer division is performed. The fractional part is discarded, so the result is 2.

4. Which operator means logical AND?
Correct Answer: B

&& is logical AND. & is the bitwise AND operator.

5. What is the value of a after: int a = 5; ++a;
Correct Answer: C

++a increments a by one. Starting from 5, a becomes 6.

6. Which operator is used for bitwise XOR?
Correct Answer: C

^ is the bitwise XOR operator in C.

What comparison is required?

Are multiple conditions involved?

Is integer or floating-point arithmetic required?

Once you understand operators well, decision-making and loops become much easier.

        INTERVIEW PREPARATION
    

🎤 Operators — Interview Questions








                    1.
                

                    What is an operator in C?
                





                An operator is a symbol that instructs C to perform an operation on one or more operands.
            








                    2.
                

                    What is the difference between = and ==?
                





                = performs assignment, while == compares two values for equality.
            








                    3.
                

                    What is the difference between logical && and bitwise &?
                





                && operates on truth values and can short-circuit. & performs bitwise AND on integer operands and does not provide logical short-circuit behavior.
            








                    4.
                

                    What is short-circuit evaluation?
                





                For &&, C skips the right operand when the left operand is false. For ||, C skips the right operand when the left operand is true.
            








                    5.
                

                    What is the difference between ++a and a++?
                





                ++a increments first and then yields the new value. a++ yields the old value first and performs the increment as a side effect.
            








                    6.
                

                    What is the purpose of the conditional operator ?: ?
                





                The conditional operator chooses between two expressions based on a condition: condition ? value_if_true : value_if_false.
            








                    7.
                

                    What is the difference between / and % for integer operands?
                





                / produces the integer quotient, while % produces the remainder.
            








                    8.
                

                    What do << and >> do?
                





                They are bitwise shift operators. << shifts bits left and >> shifts bits right. Their exact behavior depends on the operand type and shift count.
