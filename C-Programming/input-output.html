⌨️ 5. Input & Output

🎓 Concept-First Explanation

This lesson is organized in the same order a faculty member would normally teach it: meaning → purpose → syntax/model → internal working → examples → common confusion → safe use. The guided examples from the earlier lesson are preserved afterward for reinforcement.

5.1 Input and Output Are Stream Operations

The standard I/O library models input and output using streams. A hosted C program begins with standard streams such as stdin, stdout and stderr. Functions such as printf, scanf, fgets and fputs operate through this model.

StreamTypical purpose
stdinstandard input
stdoutnormal program output
stderrdiagnostic/error output

5.2 printf() — Format String Plus Arguments

printf("Name: %s  Age: %d  CGPA: %.2f\n", name, age, cgpa);

The format string contains ordinary characters plus conversion specifications. Each conversion specification tells printf how to interpret the corresponding argument. If the argument type does not match what the conversion expects, behavior may be undefined.

Think of the format as a contract

%d says “the corresponding argument is an int value.” %f in printf says “the corresponding argument arrives as double.”

5.3 Anatomy of a printf Conversion Specification

% [flags] [width] [.precision] [length] conversion
printf("%8d", n);      /* minimum field width 8 */
printf("%08d", n);     /* zero padding */
printf("%-8d", n);     /* left aligned */
printf("%.2f", x);     /* two digits after decimal */
printf("%10.2f", x);   /* width 10, precision 2 */

Width is generally a minimum field width, not a maximum. Precision has conversion-specific meaning.

5.4 Why printf Uses %f for Both float and double Arguments

In calls to variadic functions such as printf, a float argument undergoes the default argument promotions and is passed as double. Therefore %f expects a double argument. For printf, %lf has the same effect as %f for floating output in modern C.

float f = 7.25f;
double d = 71.2357455;
printf("%f\n", f);
printf("%f\n", d);

5.5 scanf() Is Different Because It Receives Pointers to Destinations

scanf must store converted input into objects supplied by the caller, so most conversions require addresses.

int age;
double salary;
scanf("%d", &age);
scanf("%lf", &salary);
scanf conversionExpected destination pointer
%dint *
%uunsigned int *
%ffloat *
%lfdouble *
%cchar *

5.6 Why & Is Usually Needed in scanf()

Suppose age is an int. The expression &age produces its address, which has type int *. scanf uses that address to write the converted input into the caller’s object.

age object
address: 0x1000
value:   (to be filled)
   ↑
scanf receives &age = 0x1000 and stores the converted int there

5.7 Why %s with a Character Array Usually Has No &

char name[20];
scanf("%19s", name);

In most expressions an array name such as name is converted to a pointer to its first element. That already supplies a char * destination. Writing &name produces a pointer to the whole array, which is a different pointer type.

Safety

Always provide a width limit with %s when the buffer size is known. For a 20-element array, %19s leaves room for the terminating null character.

5.8 Reading a Line: Prefer fgets When Spaces Matter

char line[100];

if (fgets(line, sizeof line, stdin) != NULL)
{
    printf("You entered: %s", line);
}

%s stops at whitespace. fgets reads a line-like sequence up to the size limit, newline or end-of-file. When a newline is read and space is available, it remains in the array; programs often remove it explicitly when needed.

5.9 The “Newline Left Behind” Problem

int age;
char ch;

scanf("%d", &age);
scanf("%c", &ch);   /* may read the pending newline */

Formatted input often leaves characters that do not belong to the requested conversion. A following %c does not skip whitespace by default, so it may consume a newline. One simple formatted-input pattern is scanf(" %c", &ch), where leading whitespace in the format tells scanf to skip input whitespace. For line-oriented input, using fgets consistently is often clearer.

5.10 Always Check Input Function Return Values

int n;
if (scanf("%d", &n) != 1)
{
    fprintf(stderr, "Invalid integer input\n");
    return 1;
}

scanf returns the number of successful assignments, or EOF when input failure occurs before the first conversion. Ignoring the return value can leave variables unchanged or invalid for later logic.

5.11 Character I/O and Escape Sequences

int c = getchar();
if (c != EOF)
    putchar(c);

getchar returns int, not char, so it can represent every unsigned-char value plus the distinct EOF indicator. Escape sequences such as \n, \t, \\ and \" represent special characters inside literals.

5.12 Output Precision vs Stored Precision

double d = 71.2357455;
printf("%f\n", d);
printf("%.3f\n", d);
printf("%.10f\n", d);

Changing the format precision changes how the value is converted to text for output; it does not change the stored type from double to something more or less precise.

5.13 A Reliable Input/Output Workflow

Prompt → Read → Check return status → Validate range/meaning → Process → Format output

Separating syntactic conversion (“did the user enter an integer?”) from semantic validation (“is the integer between 1 and 100?”) leads to much safer programs.

5.14 Common I/O Mistakes and Their Causes

MistakeWhy it is a problem
Using wrong format specifierVariadic functions rely on the format to interpret arguments correctly.
Forgetting & for numeric scanf destinationFunction needs an address to store the result.
Using %f instead of %lf for double * in scanfThose conversions expect different pointer types.
Unbounded %sCan overrun the destination array.
Ignoring return valueFailed conversion may leave program state unsuitable.
Mixing token and line input without handling pending newlineLater reads may consume leftover whitespace.

5.15 Quick Revision

📌 printf() is commonly used for formatted output.

📌 scanf() is commonly used for formatted input.

📌 %d → int
📌 %u → unsigned int
📌 %c → char
📌 %f → floating-point output
📌 %lf → double input with scanf()
📌 %s → string
📌 \n → new line
📌 &variable gives the address of a variable.

5.18 Key Takeaway

🎯 For every input/output problem, remember:

1. Identify the input data.

2. Choose the correct data type.

3. Use the correct scanf() format.

4. Process the data.

5. Use the correct printf() format.

This pattern is the foundation of almost every beginner coding-platform problem.

🎤 Input & Output — Interview Questions







1.
What is the purpose of printf() in C?





                printf() writes formatted output to the standard output stream according to its format string and arguments.
            







2.
What is the purpose of scanf() in C?





                scanf() reads formatted input from the standard input stream and stores converted values in objects whose addresses are provided.
            







3.
Why is & used with ordinary scalar variables in scanf()?





                scanf() needs the address of the destination object so that it can store the converted input value there.
            







4.
Why is there often a space before %c in scanf(" %c", &ch)?





                Whitespace in a scanf format string tells scanf() to skip leading whitespace characters before reading the character.
            







5.
What is the difference between %f and %lf for scanf()?





                %f expects a pointer to float, while %lf expects a pointer to double.
            







6.
Why can scanf("%s", name) read only one word?





                %s skips leading whitespace and then reads a sequence of non-whitespace characters, so it stops at the next whitespace character.
            







7.
What is the difference between '
' and '	'?





                
 represents a newline, while 	 represents a horizontal tab.
            









PLACEMENT TIPS

💡 Input & Output — Extra Tips


    

  • For scanf(), always match the conversion specifier with the correct pointer type.
    • 

  • Remember the important difference: scanf() uses %lf for double, while printf() uses %f for double output.
    • 

  • When reading a character after numeric input, understand why scanf(" %c", &ch) is often safer than scanf("%c", &ch).
    • 

  • When reading a string with %s, use a field width such as %29s for a 30-character array.
    • 

  • In coding tests, check the required output format carefully. Extra spaces, labels, or missing line breaks can cause a correct calculation to be judged wrong.
