🧮 Expressions in C

An expression is a combination of operands, operators and function calls that C evaluates to produce a value, perform an operation, or both.

Why are expressions important?

Expressions are everywhere in C. Calculations, comparisons, conditions, assignments, function arguments, array indexes and return statements all depend on expressions.

The basic idea

Operands + Operators
        ↓
    Expression
        ↓
     Evaluation
        ↓
      Result

8.1 What Is an Expression?

An expression is a piece of C code that can be evaluated according to C's rules. 

10 + 5

The expression above evaluates to 15.

Another example:

a * b + 10

Here, the variables and constant are operands and the arithmetic symbols are operators.

Expression What it does
10 + 20 Calculates a value
a > b Produces a comparison result
x = 25 Assigns a value
printf("%d", x) Calls a function
i++ Uses an increment operation

8.2 Expression vs Statement

An expression and a statement are related, but they are not the same thing. 

a + b

This is an expression. 

a + b;

This is an expression statement. The semicolon turns the expression into a statement.

Expression Statement
x + y x + y;
Produces/evaluates a value or performs an operation Forms a complete executable statement
Can be part of a larger expression Can stand as a statement in a program
Important distinction

Not every statement is an expression. For example, an if statement is not an expression.

8.3 Operands

An operand is the value or object that an operator acts upon. 

20 + 5

Here:

  • 20 is an operand.
  • + is the operator.
  • 5 is another operand.

For a unary operator:

-x

x is the operand and - is a unary operator.

8.4 Simple Expressions

A simple expression may contain a single constant or variable. 

25
x
temperature

These can participate in larger expressions. 

x + 25
temperature - 5
price * quantity

8.5 Compound Expressions

A compound expression contains multiple operations. 

a + b * c - d

C cannot simply evaluate this from left to right without considering operator rules. Operator precedence and associativity determine how the expression is grouped. 

a + b * c
    ↓
a + (b * c)
    ↓
final result

8.6 How C Evaluates an Expression

Evaluation means determining the result of an expression according to C's rules. 

int result;

result = 10 + 5 * 2;

Multiplication has higher precedence than addition. Therefore the expression is grouped as: 

10 + (5 * 2)

So: 

10 + 10 = 20
Remember

Precedence determines which operator binds more strongly. Associativity determines grouping when operators of the same precedence are involved.

8.7 Parentheses in Expressions

Parentheses can explicitly control grouping. 

int a = 10;
int b = 5;
int c = 2;

int result = a + b * c;

This gives:

10 + (5 * 2) = 20

But: 

int result = (a + b) * c;

gives:

(10 + 5) * 2 = 30
Good practice

Use parentheses when they make your intended grouping clearer, even when precedence already determines the result.

8.8 Arithmetic Expressions

Arithmetic expressions use operators such as +, -, *, / and %. 

int a = 20;
int b = 6;

int sum = a + b;
int difference = a - b;
int product = a * b;
int quotient = a / b;
int remainder = a % b;
Expression Result
20 + 6 26
20 - 6 14
20 * 6 120
20 / 6 3
20 % 6 2

8.9 Integer Expressions

When integer operands are used with arithmetic operators, the operation follows integer arithmetic rules. 

int a = 7;
int b = 2;

printf("%d\n", a / b);

Output:

3

The fractional part is not preserved by integer division.

Division rule

For integer operands, the result of division is truncated toward zero. 

7 / 2   → 3
-7 / 2  → -3
7 / -2  → -3

8.10 Floating-Point Expressions

When floating-point operands participate in an expression, floating-point arithmetic can be performed. 

double a = 7.0;
double b = 2.0;

double result = a / b;

printf("%.2f\n", result);

Output:

3.50
Common confusion

The expression 7 / 2 and 7.0 / 2.0 are not equivalent.

8.11 Mixed-Type Expressions

An expression may contain operands of different types. C applies its conversion rules to determine how the operation is performed. 

int a = 10;
double b = 3.0;

double result = a / b;

The integer value is converted as necessary so the division can be performed in the appropriate common type. 

10 / 3.0 → 3.333333...
Different operand types
          ↓
Conversions
          ↓
Common arithmetic type
          ↓
Operation
          ↓
Result

8.12 Type Conversion Inside Expressions

C can perform conversions automatically in many expressions.

Implicit conversion

int a = 10;
double b = 2.5;

double result = a + b;

The integer value participates in the floating-point calculation through the applicable conversion rules.

Explicit conversion

int a = 7;
int b = 2;

double result = (double)a / b;

The cast (double)a explicitly converts a before the division.

Important

Casting only one operand can change the type of an entire arithmetic operation.

8.13 Using Casts to Control Expression Results

int total = 7;
int count = 2;

double average = (double)total / count;

Without the cast: 

double average = total / count;

The division is performed using integer operands first, producing 3, which is then converted to double.

With the cast, the division itself is floating-point: 

(double)7 / 2 → 3.5

8.14 Relational Expressions

Relational operators compare values. 

10 > 5
10 < 5
10 == 10
10 != 5

In C, relational and equality operators produce an int result: 

1 → true
0 → false
Expression Result
10 > 5 1
10 < 5 0
10 == 10 1
10 != 10 0

8.15 Logical Expressions

Logical operators combine or invert conditions. 

int age = 20;
int hasID = 1;

int allowed = (age >= 18) && hasID;

The two conditions must both be logically true for && to produce true.

Operator Meaning
&& Logical AND
|| Logical OR
! Logical NOT

8.16 Truth Values in C Expressions

C does not require a separate Boolean type for ordinary language conditions. In a condition, zero represents false and a nonzero value represents true. 

if (0)
{
    /* not executed */
}

if (25)
{
    /* executed */
}

This rule also affects logical operators. 

!0     → 1
!25    → 0
!-10   → 0
Remember

Logical operators interpret zero as false and nonzero values as true.

8.17 Short-Circuit Evaluation

The logical operators && and || can stop evaluating their right-hand operand when the result is already known.

Logical AND

0 && something

Since the left side is false, the complete AND expression must be false. The right side is not evaluated.

Logical OR

1 || something

Since the left side is true, the complete OR expression must be true. The right side is not evaluated. 

AND:
false && anything
       ↓
     false

OR:
true || anything
      ↓
     true
Practical use

Short-circuit evaluation is commonly used to protect operations such as checking a pointer or validating a condition before using another expression.

8.18 Assignment Expressions

Assignment itself is an expression in C. 

int x;

x = 25;

The expression x = 25 stores the value 25 in x.

Because assignment is an expression, it can participate in larger expressions. 

int a;
int b;

a = b = 10;

Assignment associates from right to left, so this is grouped as: 

a = (b = 10);

Both variables become 10.

8.19 Compound Assignment Expressions

C provides operators that combine an operation with assignment.

Compound Conceptual equivalent
x += 5 x = x + 5
x -= 5 x = x - 5
x *= 5 x = x * 5
x /= 5 x = x / 5
x %= 5 x = x % 5

Bitwise and shift compound assignments are also available: 

&=   |=   ^=   <<=   >>=

8.20 Increment and Decrement Expressions

The increment and decrement operators modify a value by one. 

i++;
++i;

i--;
--i;

Prefix

int i = 5;
int x = ++i;

The value is incremented first, so: 

i = 6
x = 6

Postfix

int i = 5;
int x = i++;

The old value is used for the expression, then i is incremented: 

x = 5
i = 6
Easy way to remember

Prefix: change first, use later.

Postfix: use first, change afterward.

8.21 Conditional Expression

The conditional operator ?: provides a compact way to select between two expressions. 

condition ? expression1 : expression2

Example:

int a = 20;
int b = 15;

int larger = (a > b) ? a : b;

Since a > b is true, larger receives 20. 

condition
    |
    +---- true  → expression1
    |
    +---- false → expression2

8.22 The sizeof Operator

sizeof determines the size, in bytes, of an object or type. 

int x;

printf("%zu\n", sizeof(x));
printf("%zu\n", sizeof(int));

The exact size of most C types is implementation-dependent. Therefore, do not assume that an int is always a particular number of bytes on every platform.

Important

The result of sizeof has type size_t.

%zu is the standard printf conversion specifier for size_t in modern C.

For most ordinary expressions, the operand of sizeof is not evaluated. 

int x = 10;

sizeof(x++);

Here, x is not incremented because sizeof determines the type/size without evaluating this non-VLA operand.

8.23 The Comma Operator

The comma operator evaluates its left operand first, discards that result, then evaluates the right operand. The value of the complete comma expression is the value of the right operand. 

int x;

x = (10, 20);

The comma expression produces 20, so x becomes 20.

Important distinction

The commas separating function arguments are not automatically comma operators. 

printf("%d %d", a, b);

Here the commas separate function arguments.

8.24 Bitwise Expressions

Bitwise operators work on integer operands at the level of individual bits. 

&   Bitwise AND
|   Bitwise OR
^   Bitwise XOR
~   Bitwise NOT / complement
<<  Left shift
>>  Right shift

These operators are especially important in systems programming, embedded programming, flags, masks, networking and performance-sensitive code.

8.25 Bitwise AND Expression

Bitwise AND produces a 1 only when both corresponding bits are 1. 

5 = 0101
3 = 0011

5 & 3

0101
0011
----
0001

Result = 1

8.26 Bitwise OR Expression

5 = 0101
3 = 0011

0101
0011
----
0111

Result = 7

A bit becomes 1 if at least one corresponding input bit is 1.

8.27 Bitwise XOR Expression

XOR produces 1 when the corresponding bits are different. 

5 = 0101
3 = 0011

0101
0011
----
0110

Result = 6

8.28 Bitwise Complement ~

The bitwise complement operator ~ flips every bit of its integer operand.

Every 0 becomes 1, and every 1 becomes 0. 

~x

Conceptual 8-bit example

5

Binary:
00000101

Apply ~:

11111010

On a typical modern system using two's-complement signed integers, that resulting bit pattern represents -6. 

~5 → -6
Why does this happen?

On a two's-complement system, the identity ~x == -x - 1 holds for signed integer values. 

~5
= -5 - 1
= -6

This is a useful rule for modern two's-complement systems, but when discussing C's abstract rules, remember that integer representation details matter.

Do not confuse ~ and !

Operator Meaning Example
~ Bitwise complement ~5
! Logical NOT !5 
!5 → 0

~5 → bitwise complement of 5
Important concept

! asks whether a value is logically false. ~ changes the individual bits of an integer.

8.29 Shift Expressions

Shift operators move bits left or right.

Left shift

5 << 1

Conceptually:

0101
 ↓ shift left
1010

Result = 10

Right shift

20 >> 2

For a positive integer, this commonly corresponds to moving the bits two places to the right.

Shift safety

The shift count must not be negative and must be less than the width of the promoted left operand. Violating these requirements results in undefined behavior.

Right shifting an unsigned value shifts in zero bits. For a negative signed value, the result is implementation-defined.

8.30 Operator Precedence

Operator precedence determines how operators are grouped when an expression contains different operators. 

int result = 2 + 3 * 4;

Multiplication has higher precedence than addition: 

2 + (3 * 4)
= 14

Parentheses can override the natural grouping: 

(2 + 3) * 4
= 20
Parentheses
     ↓
Higher-precedence operators
     ↓
Lower-precedence operators

A complete precedence and associativity table is covered later in the dedicated Operator Precedence & Associativity lesson.

8.31 Associativity

Associativity determines how operators of the same precedence are grouped.

Example: arithmetic operators

20 - 5 - 3

The subtraction operators have the same precedence and associate from left to right: 

(20 - 5) - 3
= 12

Example: assignment

a = b = 10;

Assignment associates from right to left: 

a = (b = 10);
Precedence vs associativity

Precedence answers: Which operator binds more strongly?

Associativity answers: How are operators with the same precedence grouped?

8.32 Function Call Expressions

A function call can appear as part of an expression when the called function returns a value. 

int result = square(5);

If square(5) returns 25, the complete expression can be used in the assignment. 

int total = square(5) + 10;

Function calls and their evaluation rules become more important when functions are covered in detail.

8.33 Array Subscript Expressions — Preview

The subscript operator [] is used to access an array element. 

int marks[3] = {80, 90, 75};

int x = marks[1];

Here marks[1] accesses the second element.

Arrays will be studied in depth in the later Arrays lesson.

8.34 & and * — Context Matters

Some C symbols have different meanings depending on context.

Symbol Context Meaning
& a & b Bitwise AND
& &x Address-of operator
* a * b Multiplication
* *ptr Dereference

Address-of and dereference will be studied deeply in the Pointers lesson.

8.35 Expressions with Side Effects

An expression has a side effect when its evaluation changes program state. 

i++

The expression produces a value and also changes i.

Assignment is another example:

x = 50;

It changes the stored value of x.

Write expressions clearly

Avoid trying to modify the same scalar object multiple times in one complicated expression. Clear, separate statements are usually easier to understand and safer.

8.36 Dangerous Modification Expressions

Some expressions attempt to modify and use an object in ways that violate C's sequencing rules.

For example, avoid code such as:

i = i++ + 1;

Do not try to predict a single reliable result for such expressions. The program can have undefined behavior.

Better approach 
i++;
i = i + 1;

Separate operations into clear statements when their order matters.

8.37 Lvalue and Non-Lvalue Expressions

The terminology around lvalues becomes very important in C because some expressions identify objects that can be modified. 

int x = 10;

x = 20;

Here x identifies an object that can be modified, so it can appear on the left side of assignment when it is a modifiable lvalue.

A literal such as 20 cannot be assigned to: 

20 = x;   /* invalid */
Simple mental model

A modifiable lvalue identifies a storage location that can be changed.

The complete rules for lvalues, arrays, pointers and objects become much more important in the Pointers and advanced C lessons.

8.38 Complete Expression Example

#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 3;

    int sum = a + b;
    int product = a * b;
    int remainder = a % b;

    double division = (double)a / b;

    int greater = a > b;
    int bothPositive = (a > 0) && (b > 0);

    int larger = (a > b) ? a : b;

    printf("Sum = %d\n", sum);
    printf("Product = %d\n", product);
    printf("Remainder = %d\n", remainder);
    printf("Division = %.2f\n", division);
    printf("Greater = %d\n", greater);
    printf("Both positive = %d\n", bothPositive);
    printf("Larger = %d\n", larger);

    return 0;
}

Expression analysis

Expression Purpose
a + b Arithmetic
a * b Multiplication
a % b Remainder
(double)a / b Floating-point division
a > b Relational comparison
(a > 0) && (b > 0) Logical AND
(a > b) ? a : b Conditional expression

8.39 Common Mistakes with Expressions

❌ Integer division mistake

double avg = 7 / 2;

This performs integer division first.

❌ Assignment vs comparison

if (x = 5)

This assigns 5 instead of comparing with 5.

❌ Confusing ! and ~

!x
~x

They have completely different meanings.

❌ Ignoring precedence

a + b * c

Multiplication is grouped before addition.

❌ Complicated side effects

i = i++ + 1;

Avoid expressions with problematic sequencing.

❌ Unsafe shifts

x << -1

Negative shift counts are invalid and lead to undefined behavior.

8.40 Common Confusions

Confusion Correct idea

++i vs i++ Prefix vs postfix
7 / 2 vs 7.0 / 2 Integer vs floating-point division
Precedence vs associativity Grouping strength vs same-level grouping direction

🧠 Test Your Understanding

1 What is the result of 10 + 5 * 2?
Answer:

20, because multiplication has higher precedence than addition: 

10 + (5 * 2) = 20
2 What is the difference between 7 / 2 and 7.0 / 2?
Answer:

7 / 2 uses integer division and gives 3.

7.0 / 2 performs floating-point division and gives 3.5.

3 What is the difference between ! and ~?
Answer:

! is logical NOT. It converts zero to 1 and a nonzero value to 0.

~ is bitwise complement and flips every bit of an integer operand.

4 What does ++i do differently from i++?
Answer:

++i increments before its value is used by the surrounding expression.

i++ produces the old value and performs the increment as a side effect.

5 What is short-circuit evaluation?
Answer:

It means that && and || may avoid evaluating the right-hand operand when the result is already determined by the left-hand operand.

With two int operands, integer division is performed. The fractional part is discarded, so the result is 2.











3.
Which operator has higher precedence?






















Correct Answer: B

* has higher precedence than +, assignment, and logical OR.











4.
What is the result of (10 + 5) * 2?






















Correct Answer: C

Parentheses force 10 + 5 to be grouped first. 15 * 2 gives 30.











5.
What is the value of b after int a = 5; int b = a++; ?






















Correct Answer: B

Post-increment yields the old value first, so b receives 5. The side effect then increments a to 6.











6.
What is the result of (double)5 / 2?






















Correct Answer: C

The cast converts 5 to double before division. Floating-point division is performed, so the mathematical value is 2.5.

        INTERVIEW PREPARATION
    

🎤 Expressions — Interview Questions








                    1.
                

                    What is an expression in C?
                





                An expression is a combination of operands, operators, constants, variables, and possibly function calls that produces a value.
            








                    2.
                

                    What is the difference between precedence and associativity?
                





                Precedence determines how operators of different precedence levels are grouped. Associativity resolves grouping among operators at the same precedence level.
            








                    3.
                

                    Does operator precedence determine the evaluation order of independent operands?
                





                No. Precedence determines grouping, not the general evaluation order of independent operands.
            








                    4.
                

                    Why does 5 / 2 produce 2 in an integer expression?
                





                Because both operands are integers, integer division is performed and the fractional part is discarded.
            








                    5.
                

                    What is the purpose of explicit type casting in an expression?
                





                A cast requests conversion of a value to another type, which can change how the surrounding expression is evaluated.
            








                    6.
                

                    What is the result of a relational or logical expression in C?
                





                Such expressions produce an int value: 0 for false and 1 for true when produced by relational or logical operators.
            








                    7.
                

                    Why should expressions such as i++ + ++i be avoided?
                





                They can modify the same scalar object multiple times without the sequencing required by C, which can lead to undefined behavior.
            








                    8.
                

                    How can parentheses improve expressions?
                





                Parentheses make the intended grouping explicit, improve readability, and can override the normal precedence-based grouping.
