🔤 3. Variables & Constants

3.1 Variable, Object, Identifier and Value — Four Different Ideas

A variable is a named object whose stored value may change during its lifetime. An object is a region of data storage. An identifier is a name used to refer to program entities. A value is the data represented by an object or expression. These words are related but not interchangeable.

3.3 Declaration, Definition, Initialization and Assignment

These terms answer different questions and should not be taught as synonyms.

extern int count;   /* declaration; definition expected elsewhere */
int total;          /* definition of an object */
int age = 18;       /* definition + initialization */
age = 19;           /* assignment after the object exists */
OperationWhen it happensPurpose
DeclarationTranslationIntroduces a name/type relationship.
DefinitionTranslation/program object creationProvides the entity; for an object this normally allocates storage.
InitializationWhen object begins lifetimeProvides its initial value.
AssignmentDuring executionStores a new value into an existing modifiable object.

3.4 Rules for Identifiers — and the Reason Behind Them

  • May contain letters, digits and underscore.
  • Cannot begin with a digit.
  • Keywords such as int and return cannot be reused as ordinary identifiers.
  • C is case-sensitive: total and Total are different identifiers.
  • Some identifier forms are reserved to the implementation, especially names beginning with underscores in certain contexts; beginners should avoid inventing such names.
Naming principle

Choose names that reveal meaning: studentCount communicates more than x when the value represents a student count.

3.6 Why Write 89U When the Variable Is Already unsigned?

unsigned int a = 89;
unsigned int b = 89U;

The declaration controls the type of the destination object. The suffix controls the type-selection rules for the literal expression itself. In the first initializer, 89 is an int constant because it fits; it is then converted for storage in a. In the second, 89U is an unsigned integer constant from the start.

Why it can matter

Expression types affect arithmetic conversions and comparisons before a result is finally stored. Literal suffixes are therefore about the expression, not merely about decorating the destination variable.

3.8 Where a Variable Is Declared Changes Its Scope and Lifetime

A declaration inside a block usually creates a block-scope identifier. File-scope declarations appear outside functions. Storage duration and linkage are separate concepts covered later; students should first understand that “where the name is visible” and “how long the object exists” are not the same question.

int globalCount;

int main(void)
{
    int localCount = 0;
    {
        int inner = 10;
        printf("%d", inner);
    }
    /* inner is not visible here */
}

3.9 Initialization Matters Because Uninitialized Values Differ by Storage Duration

Objects with static storage duration are zero-initialized before program startup if no explicit initializer is provided. Automatic local objects without an initializer have indeterminate values; reading such an object before giving it a valid value can be erroneous and, depending on type/state, can lead to undefined behavior.

int fileCount;       /* zero-initialized */

int main(void)
{
    int localCount;    /* not automatically initialized to zero */
    localCount = 0;    /* now explicitly initialized by assignment */
}

3.10 Variables and Memory — A Useful Model, Not a Fake Address Promise

A variable can be visualized as typed storage. The compiler decides actual addresses and may optimize aggressively, so diagrams use example addresses only to explain the idea.

Example conceptual memory

Later, pointers will let a program work with addresses explicitly.

3.11 Common Confusions to Resolve Early

ConfusionCorrect idea
Variable vs identifierThe variable is an object; the identifier is its name.
Initialization vs assignmentInitialization gives the first value as lifetime begins; assignment updates an existing object.
Constant vs literalA literal is written directly; a named constant may be a const object or macro.
89 vs 89UThe suffix changes the literal expression type-selection rules.
'A' vs "A"First is a character constant; second is a string literal.

3.12 Quick Revision

📌 A variable represents a storage location used by a program.

📌 Declaration introduces a variable with its type and name.

📌 Initialization gives an initial value when an object is defined.

📌 Assignment changes the stored value when the object is modifiable.

📌 C identifiers are case-sensitive.

📌 Keywords cannot be used as identifiers.

📌 const can make an object read-only through that identifier.

📌 #define creates a preprocessor macro.

3.13 Quick MCQs

Select an answer first, then click Check Answer. Your choice will be marked immediately, and the correct answer with explanation will appear below.

1. Which symbol is used for assignment?
Correct Answer: B

The single equals sign (=) is the assignment operator in C. It stores the value of the right-hand expression in the object on the left.

2. Which is a valid identifier?
Correct Answer: C

student_name is valid because it begins with a letter and contains only letters and an underscore. An identifier cannot start with a digit, contain spaces, or use a C keyword such as float.

3. Which keyword can be used to qualify an object as read-only?
Correct Answer: C

const is the C type qualifier used to indicate that an object should not be modified through that identifier.

4. Which of the following is case-sensitive in C?
Correct Answer: A

C identifiers are case-sensitive. For example, age, Age, and AGE are treated as different identifiers.

5. Which is a valid declaration?
Correct Answer: B

int age; is valid because int is a C type keyword and age is a valid identifier. Identifiers cannot begin with a digit, and integer/number are not C built-in type keywords.

INTERVIEW PREPARATION
🎤 Variables & Constants — Interview Questions
1.What is a variable in C?
A variable is a named object that represents a storage location used by a C program. Its value can generally change during program execution.
2.What is the difference between declaration, initialization and assignment?
Declaration introduces the variable's type and name. Initialization gives an initial value when the object is defined. Assignment stores a value in an already declared modifiable object.
3.What rules should a C identifier follow?
An identifier may contain letters, digits and underscores; it must not start with a digit; spaces are not allowed; keywords cannot be used; and C identifiers are case-sensitive.
4.What is the difference between const and #define?
const qualifies an object in the C language, while #define creates a preprocessor macro that is replaced before compilation.
5.Why are meaningful variable names important?
Meaningful names make programs easier to read, understand, debug and maintain.


PLACEMENT TIPS
💡 Variables & Constants — Extra Tips
  • Be ready to explain the difference between declaration, initialization, and assignment with one short example.
  • Remember that an uninitialized automatic local variable has an indeterminate value; do not use it before assigning a valid value.
  • Do not confuse = with ==. Assignment stores a value; equality comparison checks whether values are equal.
  • Use meaningful variable names in coding rounds because readable code is easier to verify and debug.
  • Know the practical difference between a const-qualified object and a #define macro.
