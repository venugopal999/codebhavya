📦 4. Data Types

🎓 Concept-First Explanation

This lesson is organized in the same order a faculty member would normally teach it: meaning → purpose → syntax/model → internal working → examples → common confusion → safe use. The guided examples from the earlier lesson are preserved afterward for reinforcement.

4.1 Why C Needs Data Types

A type tells the compiler how a value is represented and what operations are meaningful. The same bit pattern can have different interpretations depending on type, so a data type is not simply “how many bytes a variable occupies.”

4.3 Integer Types and Modifiers

C provides several integer type families. signed, unsigned, short and long participate in forming integer types.

Common spellingMeaning
shortshort int
unsignedunsigned int
longlong int
unsigned longunsigned long int
long longlong long int

4.4 Do Not Memorize “int = 4 Bytes” as a Language Rule

The C standard specifies ordering and minimum capabilities for integer types rather than one universal byte size. On many current desktop systems int is 4 bytes, but a program should use sizeof, limits macros and fixed-width types when exact properties matter.

printf("sizeof(int) = %zu\n", sizeof(int));
printf("sizeof(long) = %zu\n", sizeof(long));
Why int and long can both be 4 bytes

C requires long to provide at least the range required by int, not necessarily to occupy more bytes on every implementation. On other data models, long may be wider.

4.5 char, signed char and unsigned char

All three are distinct integer types. Plain char is the type normally used to store character data, but whether plain char behaves as signed or unsigned for values outside the basic character range is implementation-defined.

char letter = 'A';
signed char temperatureDelta = -10;
unsigned char byteValue = 250;
Why can signed char hold -10?

Because signed char is an integer type. The word “char” does not mean the object must always contain a character literal. Character encoding values are one important use of character types, not their only possible values.

4.6 _Bool and bool

The built-in boolean integer type is _Bool. The standard header <stdbool.h> historically provides convenient boolean macros such as bool, true and false in language versions where they are defined by that header. In modern code, check the targeted C standard/compiler mode.

#include <stdbool.h>

bool ready = true;

4.7 Floating-Point Types and Precision

float, double and long double represent floating-point values with implementation-defined formats that meet standard requirements. Precision describes how many significant digits can be represented reliably; it does not dictate how many digits printf displays.

double x = 71.2357455;
printf("%f\n", x);      /* default: 6 digits after decimal for %f */
printf("%.10f\n", x);   /* request 10 digits after decimal */
Critical distinction

Storage precision and output formatting precision are different. A double may carry roughly 15–17 significant decimal digits on common IEEE-754 systems, while printf("%f", x) still defaults to six digits after the decimal point.

4.8 void — Absence of a Value/Specified Object Type

void is used when a function returns no value, to state that a function takes no parameters in a prototype such as f(void), and as void * for generic object pointers. You cannot create an ordinary object of type void because it has no size for such an object.

4.9 sizeof and What It Measures

sizeof yields the size in bytes of a type or object representation, where one C byte is CHAR_BIT bits. The result type is size_t.

sizeof(char)          /* always 1 C byte */
sizeof(int)
sizeof(double)
sizeof array / sizeof array[0]  /* element count only while array is still an array */

4.10 Use limits.h, float.h and stdint.h Instead of Guessing

#include <limits.h>
#include <float.h>
#include <stdint.h>

printf("INT_MAX = %d\n", INT_MAX);
printf("DBL_DIG = %d\n", DBL_DIG);

int32_t id;   /* available only if implementation provides exactly 32-bit type */

<limits.h> describes integer limits, <float.h> describes floating characteristics, and <stdint.h> provides exact-width and related integer typedefs when supported.

4.11 Type Qualifiers Are Not New Numeric Types

const, volatile and restrict qualify types and affect how objects/pointers may be used or optimized. They should not be mixed conceptually with size modifiers such as short and long.

QualifierCore idea
constProgram should not modify the object through that qualified lvalue.
volatileAccesses are observable and may reflect changes outside ordinary program flow; does not make operations atomic.
restrictPointer qualification used to express non-aliasing promises within its rules.

4.12 Conversion Is Part of Expression Evaluation

C automatically converts values in many contexts: integer promotions, usual arithmetic conversions, assignment, function calls with prototypes and explicit casts. The destination type is only one part of the story; an intermediate expression may be evaluated in another type before assignment.

double a = 5 / 2;      /* integer division first -> 2, then converted to 2.0 */
double b = 5 / 2.0;    /* one operand double -> floating computation -> 2.5 */

4.13 Common Data-Type Misconceptions

MythReality
int is always 4 bytesCommon, not guaranteed.
long must be larger than intIt must meet at least the required range relationship; size can be equal.
char only stores lettersCharacter types are integer types.
double always prints 15 decimal placesOutput formatting is separate from representation precision.
sizeof(char) means 8 bitsIt is always 1 C byte; CHAR_BIT tells how many bits are in a byte.

4.14 Quick Revision

📌 char is used for character values.

📌 int is commonly used for integer values.

📌 float represents single-precision floating-point values.

📌 double represents double-precision floating-point values.

📌 void represents the absence of a value in certain contexts.

📌 sizeof reports size in bytes.

📌 Use sizeof() when you need the actual size on your system.

📌 Integer division discards the fractional part of the result.

1. Which data type is commonly used to store an integer?
Correct Answer: B

int is the standard integer type commonly used for whole-number values.

2. Which operator gives the size of a type or object?
Correct Answer: C

sizeof is a C operator that reports the size in bytes of a type or object.

3. Which is a character constant?
Correct Answer: B

A character constant is written inside single quotes, such as 'A'. Double quotes create a string literal.

4. What is the result of 5 / 2 when both operands are int?
Correct Answer: C

When both operands are integers, integer division is performed, so the fractional part is discarded and the result is 2.

5. Which type generally provides more precision than float?
Correct Answer: C

double generally provides greater floating-point precision than float, although exact representation details are implementation-dependent.

4.17 Key Takeaway

🎯 Don't simply memorize data types.

Understand three things:

1. What kind of value do I need?

2. What type is appropriate?

3. What happens when different types are used together?

These ideas become extremely important when we learn operators, expressions, arrays, pointers and functions.

INTERVIEW PREPARATION

🎤 Data Types — Interview Questions







1.
What is a data type in C?





                A data type tells the compiler what kind of value an object can represent and helps determine how that object is stored and interpreted.
            







2.
What are the main categories of C data types?





                Common categories include basic/fundamental types, void, derived types such as arrays, pointers and functions, and user-defined types such as struct, union and enum.
            







3.
What is the difference between float and double?





                Both represent floating-point values, but double generally provides greater precision than float. Exact representation and precision are implementation-dependent.
            







4.
What is the purpose of sizeof?





                sizeof reports the size in bytes of a type or object. Its result has type size_t.
            







5.
What is the difference between implicit and explicit type conversion?





                Implicit conversion is applied automatically according to C language rules. Explicit conversion is requested by the programmer using a cast.
            







6.
Why does 5 / 2 produce 2 in an integer expression?





                Because both operands are integers, integer division is performed and the fractional part is discarded.
            







7.
What is the purpose of signed and unsigned integer types?





                signed integer types can represent negative and non-negative values, while corresponding unsigned types represent only non-negative values and have a different range.
            









PLACEMENT TIPS

💡 Data Types — Extra Tips


    

  • Do not memorize fixed byte sizes for every machine. Except for sizeof(char) == 1, sizes of fundamental types are implementation-dependent.
    • 

  • Know the correct format specifier for common types and remember that scanf uses %lf for double.
    • 

  • Be ready to explain why integer division can produce a different result from floating-point division.
    • 

  • Understand when a cast such as (double)a changes the type used by an expression.
    • 

  • In interviews, connect type + range/precision + operation behavior instead of memorizing only syntax.
