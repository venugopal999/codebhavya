🏗️ 14. Structures & Unions

🎓 Concept-First Explanation

This lesson is organized in the same order a faculty member would normally teach it: meaning → purpose → syntax/model → internal working → examples → common confusion → safe use. The guided examples from the earlier lesson are preserved afterward for reinforcement.

14.1 Why Structures Exist

An array groups many values of the same type. A structure groups related members that may have different types into one aggregate object.

struct Student
{
    int id;
    char name[40];
    double cgpa;
};

14.2 Tag, Type and Structure Object

struct Student s1;
struct Student s2 = {101, "Asha", 8.7};

Student is a structure tag used with the struct keyword in this declaration form. s1 and s2 are separate structure objects with their own member storage.

14.3 Member Access with .

s1.id = 102;
printf("%d\n", s1.id);

The dot operator selects a member from a structure/union object. An array member such as name cannot be assigned with = after initialization; copy text with an appropriate string operation or element-wise logic.

14.4 Initialization and Designated Initializers

struct Student a = {101, "Asha", 8.7};
struct Student b = {.cgpa = 9.1, .id = 102, .name = "Bala"};

Designated initializers make the member being initialized explicit and reduce dependence on member order. Unspecified members in an aggregate initializer are initialized as required by the language.

14.5 Arrays of Structures

struct Student class[60];
for (size_t i = 0; i < count; i++)
    printf("%d %.2f\n", class[i].id, class[i].cgpa);

The outer array provides repeated records; each element is a complete struct Student. This is a natural representation for tables of fixed-shape records.

14.6 Passing Structures to Functions

void printStudent(struct Student s);
void updateCgpa(struct Student *s, double value);

Passing a structure by value copies its value into the parameter. Passing a pointer avoids copying and can allow the function to modify the caller’s structure. Use const struct Student * when the function should only read it.

14.7 Pointer to Structure and ->

struct Student *p = &s1;
printf("%d", p->id); /* same member as (*p).id */

The arrow operator performs dereference-plus-member-selection in one readable form.

14.8 Nested Structures and Self-Referential Structures

struct Date { int day, month, year; };
struct Employee { int id; struct Date joined; };

struct Node
{
    int data;
    struct Node *next;
};

A structure cannot contain a complete member of its own type recursively because that would require infinite size, but it can contain a pointer to its own type. This enables linked data structures.

14.9 Structure Layout: Alignment and Padding

Compilers may insert padding bytes so members satisfy alignment requirements. Therefore structure size can be larger than the sum of member sizes, and layout can vary across implementations/ABIs.

struct Example
{
    char c;
    int i;
};
printf("%zu", sizeof(struct Example));

Use offsetof from <stddef.h> when you need member offsets in portable source. Do not guess offsets from a hand-drawn diagram.

14.10 Structure Assignment: Value Copy and the Shallow-Copy Issue

struct Pair { int a, b; };
struct Pair x = {1,2};
struct Pair y = x; /* members copied */

Structure assignment copies member values. If a member is a pointer, the pointer value is copied—not the separately allocated object it may point to. Two structures can therefore end up pointing to the same allocation. A “deep copy” requires explicit allocation and copying logic.

14.11 What a Union Changes

union Value
{
    int i;
    double d;
    char text[16];
};

Union members overlap the same storage rather than occupying separate regions simultaneously. The union is large/aligned enough for its members, and at a given time the program must track which member representation is valid for its design.

14.12 Structure vs Union

StructureUnion
Each member has its own storage within the object.Members overlap the same storage.
Several members can hold independent values at once.Writing one member generally changes the shared representation seen by others.
Size includes members plus padding.Size is sufficient for the largest/alignment-demanding member plus any padding.

14.13 Tagged Union Pattern

enum ValueKind { VALUE_INT, VALUE_DOUBLE };

struct Value
{
    enum ValueKind kind;
    union { int i; double d; } data;
};

The separate tag tells the program which union member is currently intended to be read. This pattern makes variant data much safer and clearer.

14.14 Bit-Fields

struct Status
{
    unsigned ready : 1;
    unsigned error : 1;
    unsigned mode  : 2;
};

A bit-field requests a member with a limited number of bits and is useful for compact flags or implementation-facing layouts. Allocation order, padding and exact layout have implementation-defined aspects, so bit-fields should not be assumed to match a network/file protocol without verified implementation rules.

14.15 Flexible Array Member

struct Packet
{
    size_t length;
    unsigned char data[];
};

A flexible array member appears last in a structure and contributes no fixed element storage to sizeof the structure. Programs can allocate extra bytes after the fixed structure and treat them as the flexible member according to the language rules.

14.16 Do Not Dump Raw Structures as a Portable File Format

Padding, endianness, type sizes and representation can differ across machines or compiler settings. Writing raw structure bytes with fwrite may be useful for controlled same-platform data, but a portable file/network format should serialize fields explicitly with defined widths and byte order.

14.17 Guided Examples & Reinforcement

Now revisit the original worked examples, short explanations and visual examples. They are retained here to reinforce the concepts explained above.

What is a Structure?

A structure is a user-defined data type that allows us to group different types of data under one name.

For example, a student may have:

  • Name → character array
  • Age → integer
  • Marks → float
  • Roll number → integer

Instead of storing these as unrelated variables, we can group them using a structure.

Student

├── Roll Number
├── Name
├── Age
└── Marks

Structure Syntax

struct Student
{
    int roll;
    char name[50];
    float marks;
};

Here Student is the structure tag.

Creating a Structure Variable

struct Student s1;

Now s1 is a variable of type struct Student.

Accessing Structure Members

The dot . operator is used to access members of a structure variable. 

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s1;

    s1.roll = 101;

    s1.marks = 85.5;

    printf("Roll = %d\n", s1.roll);

    printf("Marks = %.2f\n", s1.marks);

    return 0;
}
Roll = 101
Marks = 85.50

Assigning a String to a Structure Member

A character array cannot normally be assigned using the = operator after declaration. Use strcpy() instead. 

#include <stdio.h>
#include <string.h>

struct Student
{
    int roll;
    char name[50];
};

int main()
{
    struct Student s1;

    s1.roll = 101;

    strcpy(s1.name, "Venu");

    printf("%d\n", s1.roll);

    printf("%s\n", s1.name);

    return 0;
}
101
Venu

Structure Initialization

struct Student
{
    int roll;
    char name[50];
    float marks;
};

struct Student s1 =
{
    101,
    "Venu",
    85.5
};

Designated Initialization

C also allows members to be initialized by name. 

struct Student s1 =
{
    .roll = 101,
    .name = "Venu",
    .marks = 85.5
};
💡 Designated initialization makes the code easier to understand, especially when a structure has many members.

Taking Input into a Structure

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s;

    scanf("%d", &s.roll);

    scanf("%49s", s.name);

    scanf("%f", &s.marks);

    printf("Roll = %d\n", s.roll);

    printf("Name = %s\n", s.name);

    printf("Marks = %.2f\n", s.marks);

    return 0;
}

Array of Structures

We can create an array containing multiple structure variables. 

struct Student
{
    int roll;
    char name[50];
    float marks;
};

struct Student students[3];

Example: Multiple Students

#include <stdio.h>

struct Student
{
    int roll;
    char name[50];
    float marks;
};

int main()
{
    struct Student s[3];

    for(int i = 0; i < 3; i++)
    {
        scanf("%d", &s[i].roll);

        scanf("%49s", s[i].name);

        scanf("%f", &s[i].marks);
    }

    for(int i = 0; i < 3; i++)
    {
        printf("%d %s %.2f\n",
               s[i].roll,
               s[i].name,
               s[i].marks);
    }

    return 0;
}

Passing Structure to a Function

#include <stdio.h>

struct Student
{
    int roll;
    float marks;
};

void display(struct Student s)
{
    printf("Roll = %d\n", s.roll);

    printf("Marks = %.2f\n", s.marks);
}

int main()
{
    struct Student s = {101, 90.5};

    display(s);

    return 0;
}

Returning a Structure from a Function

#include <stdio.h>

struct Point
{
    int x;
    int y;
};

struct Point createPoint()
{
    struct Point p = {10, 20};

    return p;
}

int main()
{
    struct Point p = createPoint();

    printf("%d %d", p.x, p.y);

    return 0;
}
10 20

Pointer to Structure

struct Student
{
    int roll;
    float marks;
};

int main()
{
    struct Student s = {101, 85.5};

    struct Student *p = &s;

    printf("%d\n", p->roll);

    printf("%.2f\n", p->marks);

    return 0;
}

Arrow Operator ->

When we have a pointer to a structure, we can use -> to access its members. 

struct Student *p = &s;

p->roll;

The following two expressions are equivalent: 

p->roll

(*p).roll
📌 Structure variable → use .

📌 Structure pointer → use ->

struct Student

What is a Union?

A union is a user-defined data type similar to a structure, but all members share the same memory location. 

union Data
{
    int i;
    float f;
    char c;
};

Union Example

#include <stdio.h>

union Data
{
    int i;
    float f;
    char c;
};

int main()
{
    union Data d;

    d.i = 100;

    printf("%d\n", d.i);

    d.f = 3.14f;

    printf("%.2f\n", d.f);

    return 0;
}

A union should generally be read through the member that was most recently written, subject to the rules of the C standard.

Structure Memory

In a structure, each member has its own storage.

    float b;
    char c;
};

In a union, all members share the same memory location. Only one member's value is normally stored at a time.

typedef with Structure

typedef can create a convenient alias for a type. 

typedef struct
{
    int roll;
    char name[50];
} Student;

Now we can write: 

Student s1;

instead of: 

struct Student s1;

typedef Example

#include <stdio.h>

typedef struct
{
    int id;
    float salary;
} Employee;

int main()
{
    Employee e = {101, 45000};

    printf("%d\n", e.id);

    printf("%.2f\n", e.salary);

    return 0;
}

Self-Referential Structure

A structure can contain a pointer to another object of the same structure type. 

struct Node
{
    int data;

    struct Node *next;
};
🎯 This concept is the foundation of Linked Lists and many other data structures.

Structure Padding

The compiler may insert unused bytes between structure members to satisfy alignment requirements. 

struct Example
{
    char c;
    int x;
};

Therefore, you should not assume that the structure size is always exactly the sum of the individual member sizes. 

printf("%zu", sizeof(struct Example));

Copying Structures

Structures of the same type can be assigned directly. 

struct Student s1 = {101, "Venu", 90};

struct Student s2;

s2 = s1;

The members are copied as part of the structure assignment.

Comparing Structures

C does not provide a general == operator for comparing two structures.

Compare the required members individually. 

if(s1.roll == s2.roll &&
   s1.marks == s2.marks)
{
    printf("Equal");
}
🔍 Deeper understanding: Layout, copying and active union members

Structure members appear in declaration order, but the implementation may insert padding so each member has suitable alignment. Therefore, sizeof(struct T) can exceed the sum of member sizes. Use offsetof when examining layout; never calculate offsets by assumption. Whole-structure assignment copies each member value, but a pointer member is only copied as an address, not as a separately allocated deep copy.

struct Record {
    char flag;
    int value; /* padding may appear before this member */
};

All union members share the same storage. Writing one member and reading another is not a general-purpose portable conversion technique; the result can be implementation-defined or otherwise constrained by the standard. Track which member is active, often with an accompanying enum tag. Bit-field allocation order and padding are implementation-defined, so bit fields are unsuitable as a portable network or file format.

Common Structure Mistakes

  • Forgetting the semicolon after the structure definition.
  • Using . incorrectly with a structure pointer.
  • Using -> with an ordinary structure variable.
  • Trying to assign a character array using = after declaration.
  • Assuming structure size is always the sum of member sizes.
  • Reading a union member different from the one most recently written without understanding the relevant C rules.
Reasoning trace:
member order fixed → padding may be inserted → each member aligned → trailing padding may support arrays
📘 Standard and portability note

Use offsetof and _Alignof rather than guessing offsets. Raw structure bytes are not a portable file format.

Advanced extension: Advanced direction: flexible array members must be last and require extra allocated storage; designated initializers improve clarity when many members exist.

🧠 Deep Dive — Structures, Unions, Bit-Fields and Real Memory Layout

Bit-Fields — Storing Small Integer Fields Inside a Structure

A normal structure member occupies enough storage for its declared type. Sometimes a program needs several small flags or values that use only a few bits. A bit-field lets a structure member request a specific number of bits.

struct DeviceStatus
{
    unsigned int ready : 1;
    unsigned int error : 1;
    unsigned int mode  : 2;
};

Here, ready needs one bit, error needs one bit, and mode requests two bits. Conceptually, this can pack several small values into one allocation unit instead of giving each flag a complete integer object.

⚠️ Important portability point

Bit-fields are useful inside a program, but their exact allocation order, padding, alignment and whether a field crosses an allocation-unit boundary are implementation-defined. Therefore, do not use a C bit-field layout as a portable network packet or file format unless the target ABI is specifically controlled.

Unnamed and Zero-Width Bit-Fields

struct Flags
{
    unsigned int a : 1;
    unsigned int   : 3;  /* unnamed padding field */
    unsigned int   : 0;  /* force next field to a new allocation unit */
    unsigned int b : 1;
};

An unnamed field reserves bits without providing a member name. A zero-width unnamed field requests that the following bit-field start in a new allocation unit appropriate for the declared base type. These are layout tools, not ordinary data members.

Alignment, Padding and offsetof

Compilers often place each member at an address suitable for that member's alignment. This can create padding between members and sometimes at the end of the structure.

#include <stddef.h>
#include <stdio.h>

struct Sample
{
    char code;
    int quantity;
    double price;
};

int main(void)
{
    printf("sizeof = %zu\n", sizeof(struct Sample));
    printf("quantity offset = %zu\n", offsetof(struct Sample, quantity));
    printf("price offset = %zu\n", offsetof(struct Sample, price));
}
💡 Why should students avoid memorizing member offsets?

Because the C language does not require one universal layout for every implementation. sizeof, offsetof and the implementation's ABI tell you what the current platform actually uses.

Structure Assignment Is a Value Copy — But Pointer Members Still Point to the Same Object

struct Box
{
    int *data;
};

struct Box a = { pointer_to_array };
struct Box b = a;

The assignment copies the value of a.data into b.data. It does not allocate a second array. Therefore both structure objects can point to the same allocation. This is commonly called a shallow copy when pointer-owning structures are involved.

Memory relationship
a.data ─────┐
            ├────► same allocated array
b.data ─────┘

If one owner frees that allocation while the other still uses it, the remaining pointer becomes dangling. A true independent copy requires separately allocated storage and copying of the pointed-to data.

Tagged Union — Knowing Which Union Member Is Valid

A union can store different alternatives in the same storage, but the program needs a reliable way to know which alternative it currently represents. A common design combines an enum tag with a union.

enum ValueKind { VALUE_INT, VALUE_DOUBLE };

struct Value
{
    enum ValueKind kind;
    union
    {
        int i;
        double d;
    } data;
};

If kind == VALUE_INT, the program uses data.i. If kind == VALUE_DOUBLE, it uses data.d. This pattern makes the active interpretation explicit instead of guessing.

Flexible Array Members

struct Packet
{
    size_t length;
    unsigned char payload[];  /* must be the final member */
};

The flexible array member has no fixed number of elements inside sizeof(struct Packet). The program allocates extra bytes after the structure when it needs payload storage.

struct Packet *p = malloc(sizeof *p + n * sizeof p->payload[0]);
if (p != NULL) {
    p->length = n;
    /* p->payload[0] ... p->payload[n-1] are in the extra storage */
}
✅ Design rule

Use structures to model records, unions to represent alternatives that share storage, bit-fields only when implementation-controlled packing is appropriate, and explicit serialization code when data must be portable across machines or file versions.

INTERVIEW PREPARATION

🎤 Structures & Unions — Interview Questions







1.
What is the main difference between a structure and a union?





                Structure members have separate storage so all can hold values simultaneously; union members overlap the same storage region.
            







2.
What is the difference between . and ->?





                Use . with a structure or union object. Use -> when accessing a member through a pointer to that structure or union.
            







3.
Can one structure be assigned to another structure of the same type?





                Yes. Structure assignment copies the member values from one object to another object of compatible structure type.
            







4.
Can structures be compared directly using == in C?





                No. C does not define == or != for complete structure objects; compare the relevant members individually.
            







5.
What is a self-referential structure?





                It is a structure that contains a pointer to an object of its own structure type, commonly used for linked data structures.
            







6.
What is structure padding?





                Compilers may insert unused bytes between or after members to satisfy alignment requirements.
            







7.
What is typedef used for with structures?





                typedef can create a shorter alias for a structure type so code can use the alias without repeatedly writing struct.
            







8.
Why can union size differ from structure size?





                A union needs enough storage for its largest member plus alignment requirements, while a structure must accommodate all members with any required padding.
            









PLACEMENT TIPS

💡 Structures & Unions — Placement Tips


    

  • For record-based problems, first identify the fields that belong together and define the structure clearly.
    • 

  • When sorting an array of structures, swap the entire structure object, not only one member.
    • 

  • Remember the member-access rule: object uses ., pointer uses ->.
    • 

  • Do not memorize exact structure sizes across systems; alignment and padding can change the result.
    • 

  • For unions, remember that members share storage, so treat them as alternative representations rather than independent simultaneous fields.
    • 

  • Self-referential structures connect this C topic directly to linked lists, trees, and other dynamic data structures.
