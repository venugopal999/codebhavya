📖 1. Introduction to C Programming

🎓 Concept-First Explanation

This lesson is organized in the same order a faculty member would normally teach it: meaning → purpose → syntax/model → internal working → examples → common confusion → safe use. The guided examples from the earlier lesson are preserved afterward for reinforcement.

1.1 What C Is — and What a C Program Really Does

C is a general-purpose procedural programming language. A C program is a set of declarations, definitions and executable statements written according to the rules of the C language. The source code itself is not directly executed by the processor; it is translated into machine code by a toolchain.

Why this matters

Students often think “C code runs line by line from the file.” In reality, the source first passes through preprocessing and compilation, then object code is linked into an executable. Only then does the operating system load the executable and start the program.

C source (.c)
   ↓ preprocessing
preprocessed source
   ↓ compilation
assembly / object code
   ↓ linking
executable program
   ↓ loading
running process

1.2 History and Design Goal of C

C was developed at Bell Labs in the early 1970s, primarily by Dennis Ritchie, during the development of the Unix operating system. Its design aimed to provide high-level structured programming while still giving programmers efficient access to memory and machine-oriented operations.

That combination explains why C is often described as a “middle-level” language in textbooks: it supports functions, loops, structures and abstraction, but also pointers, bitwise operations and direct memory manipulation. “Middle-level” is an informal teaching description, not an official language classification.

1.3 Why C Is Still Important

C remains important because many operating systems, embedded systems, device drivers, language runtimes, database engines and performance-sensitive libraries contain substantial C code. Learning C also exposes concepts that higher-level languages often hide: memory layout, addresses, object lifetime, data representation and compilation.

AreaWhy C fits
Operating systemsLow-level memory access and predictable runtime model

1.4 Characteristics of C — Explained, Not Memorized

  • Procedural: programs are commonly organized as functions that perform tasks.
  • Compiled: source is translated before execution.
  • Statically typed: objects and expressions have types known during translation.
  • Portable: standard-conforming source can often be moved across systems, but sizes, representations and implementation-defined behavior must still be considered.
  • Efficient: C offers a small abstraction gap from machine operations.
  • Manual resource management: dynamic memory and many external resources must be managed explicitly by the programmer.

1.6 Compiler, Linker and Library — Different Jobs

A compiler checks and translates each translation unit. A linker combines object files and resolves external references such as calls to library functions. A library is a collection of reusable compiled functionality and declarations supplied through headers.

Common confusion

Including <stdio.h> does not “copy printf code into your program.” The header provides declarations needed for compilation; the actual implementation is supplied later by the C library and linked as appropriate.

1.7 The Four Major Translation Stages

StageTypical work
PreprocessingHandles directives such as #include, #define and conditional compilation.
CompilationParses C, checks constraints/types and translates source toward machine code.
AssemblyProduces object code from assembly representation when the toolchain uses a separate assembler stage.
LinkingCombines object files/libraries and resolves external symbols to form an executable.

1.8 Syntax Error, Constraint/Compile Error, Link Error and Runtime Problem

ProblemExample idea
Syntax/translation errorMissing token or malformed declaration.
Type/constraint diagnosticPassing an incompatible argument where a diagnostic is required.
Link errorFunction declared and called but no definition is available to the linker.
Runtime error/problemInvalid memory access or division by zero during execution.
Logical errorProgram runs but computes the wrong answer.

Students should learn to classify an error before trying random fixes. The stage at which the error appears often tells you which part of the program to inspect.

1.9 Standard C vs Compiler-Specific C

The C standard defines the language and standard library, but compilers may also provide extensions. CodeBhavya examples should prefer standard C unless an extension is explicitly identified. This makes examples easier to understand and more portable.

Important

A program compiling on one compiler does not automatically prove that every construct is portable or defined by the C standard.

1.10 How to Read a C Program as a Beginner

Use a fixed reading order: identify declarations first, then inputs, then expressions that transform values, then control flow, then outputs, and finally resource cleanup. For functions, trace calls with the values passed into parameters and the value returned.

Declarations → Input → Processing → Decisions/Loops → Output → Cleanup

1.11 Common Beginner Misconceptions

  • “The compiler executes my program.” — It translates it; the executable is run later.
  • “#include links a library.” — Inclusion is preprocessing; linking is a later stage.
  • “Every C compiler uses the same type sizes.” — Many sizes are implementation-dependent.
  • “If it compiles, the program is correct.” — Logical errors and undefined behavior may still exist.
  • “C automatically manages dynamic memory.” — Allocated memory normally must be released explicitly.

What is C?

C is a general-purpose, procedural programming language. It is one of the most important programming languages for learning programming fundamentals and problem solving.

C provides low-level memory access through pointers while also providing high-level programming features such as functions, loops and decision-making statements.

History of C

C was developed by Dennis Ritchie at Bell Labs in the early 1970s.

Important Timeline

🔹 C became widely used for system software

Features of C

  • Simple: C has a relatively small set of core language features.
  • Procedural: Programs can be organized into functions and procedures.
  • Fast: C programs can execute efficiently.
  • Portable: C programs can often be moved between different systems with limited changes.
  • Structured: Large programs can be divided into smaller functions.
  • Memory Access: Pointers provide direct access to memory addresses.
  • Extensible: Programs can be organized using reusable functions and libraries.

Why Should You Learn C?

C is particularly useful for understanding how programs work internally.

A C program is normally converted into executable machine code before it runs.

What is a Compiler?

A compiler translates source code written in a programming language into a form that the computer can execute.

💡 Example:

C Source Code → C Compiler → Executable Program
🔍 Deeper understanding: How C source becomes a running program

Saving a .c file does not create a program immediately. The preprocessor first expands directives such as #include and #define. The compiler translates the resulting C code into assembly, the assembler creates object code, and the linker combines that object code with required libraries to create the executable. A syntax error normally stops compilation; a linker error means a required definition could not be found; a run-time error occurs after the executable starts. C also has undefined behaviour: the program may compile, but the language places no requirements on what happens. Accessing outside an array is one example. This distinction explains why “it compiled” does not always mean “it is correct.”

source.c → preprocessing → compilation → assembly → linking → executable

Standard versus compiler: ISO C defines the language. GCC, Clang and MSVC are implementations. Compiler extensions may work locally but fail elsewhere, so portable examples should state when they depend on a particular implementation.

Common Beginner Mistakes

  • Forgetting the semicolon ;
  • Missing braces { }
  • Using incorrect format specifiers
  • Forgetting & in appropriate scanf() calls
  • Incorrect variable declarations
  • Confusing = with ==
Reasoning trace:
source.c → preprocess → compile → assemble → link → executable
📘 Standard and portability note

Baseline: portable hosted ISO C17. Compiler extensions should be labelled explicitly.

Advanced extension: Advanced direction: freestanding C implementations may not provide the same startup environment or full hosted library.

✓Which stage reports an unresolved call to a function that was declared but never defined?
Correct Answer: C

Object files are combined during linking; unresolved external definitions are therefore linker errors.

1.14 Practice Questions

1 Who developed the C programming language?
C was developed by Dennis Ritchie at Bell Labs in the early 1970s.
2 What type of programming language is C?
C is a general-purpose, procedural programming language.
3 What is the purpose of main()?
The main() function is the entry point of a hosted C program. Program execution begins from main().
4 What is the purpose of printf()?
printf() is used to display formatted output on the screen.
5 What is a compiler?
A compiler translates source code written in a programming language into a form that the computer can execute.
6 What is the purpose of #include?
#include tells the preprocessor to include the specified header file so the program can use its declarations, such as printf() and scanf() from stdio.h.
7 What is a pointer?
A pointer is a variable that stores a memory address. Pointers allow C programs to work directly with memory addresses.
8 Why is C called a structured language?
C supports structured programming by allowing large programs to be divided into smaller functions and organized blocks of logic.
9 Give three applications of C.
Examples include Operating Systems, Embedded Systems, Device Drivers, Compilers, Networking Software, Database Systems, IoT Devices, and System Programming.
10 Why is C important for learning Data Structures?
C helps you understand arrays, functions, pointers, memory management, algorithms, and how data is stored and manipulated internally, which are important foundations for Data Structures.
