LEARNING METHOD

Follow the engineering cycle

1. Analyse

Convert the story into operations, constraints and edge cases.

2. Model

Compare candidate structures and record the selection reason.

3. Implement

Preserve invariants while handling memory and invalid input.

4. Validate

Trace state, test boundaries and justify complexity.
