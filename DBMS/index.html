Four Stages from Foundations to Placement

PART 1 • LEVELS 1–5

Database Foundations

Build the mental models needed to understand every schema and query.

LEVEL 01🗄️

Database Foundations

Distinguish data, information, databases, DBMS software and traditional file systems.

  • Database characteristics and purpose
  • File-system limitations
  • DBMS users, roles and metadata
  • Real-world database examples
LEVEL 02🏛️

Architecture & Data Models

See how users, applications, logical schemas and physical storage fit together.

  • Three-schema architecture
  • Logical and physical independence
  • Hierarchical, network and relational models
  • One-, two- and three-tier systems
LEVEL 03🔗

ER Modelling

Turn real requirements into precise entities, attributes and relationships.

  • Keys and attribute types
  • Cardinality and participation
  • Weak entities
  • Specialization and generalization
LEVEL 04▦

Relational Model

Describe tables formally and choose keys that preserve identity and integrity.

  • Relations, tuples, attributes and domains
  • Super, candidate and primary keys
  • Foreign keys
  • Entity and referential integrity
LEVEL 05σπ

Relational Algebra

Build queries from formal operations and trace how intermediate relations change.

  • Selection and projection
  • Union, difference and product
  • Rename, joins and division
  • Expression and query-tree tracing
PART 2 • LEVELS 6–8

Correct Database Design

Use dependencies and decomposition rules instead of memorizing normal forms.

LEVEL 06X→Y

Functional Dependencies

Express how attributes determine one another and calculate what a set can infer.

  • Trivial and non-trivial dependencies
  • Armstrong axioms
  • Attribute closure and candidate keys
  • Minimal cover
LEVEL 071→3

Normalization I

Diagnose repeating groups and dependency anomalies, then reach 1NF, 2NF and 3NF.

  • Insertion, update and deletion anomalies
  • Atomic values and 1NF
  • Partial dependency and 2NF
  • Transitive dependency and 3NF
LEVEL 08BCNF

Normalization II

Handle advanced dependencies and verify whether a decomposition is actually safe.

  • BCNF and 3NF comparison
  • Multivalued dependencies and 4NF
  • Join dependencies and 5NF
  • Lossless and dependency-preserving design
PART 3 • LEVELS 9–15

SQL Mastery

Progress from valid statements to expressive, explainable and interview-ready queries.

LEVEL 09SQL

SQL Foundations

Read SQL syntax, understand its families and reason correctly about NULL.

  • SQL statement families
  • Identifiers and data types
  • NULL and three-valued logic
  • Portable SQL and dialect differences
LEVEL 10DDL

Database Definition

Create schemas and enforce valid data at the database boundary.

  • CREATE, ALTER, DROP and TRUNCATE
  • Primary and foreign keys
  • UNIQUE, CHECK and DEFAULT
  • Schema evolution decisions
LEVEL 11DML

Data Manipulation

Insert and change rows safely while predicting constraints and side effects.

  • Single and multi-row INSERT
  • Targeted UPDATE
  • Safe DELETE
  • MERGE/upsert patterns
LEVEL 12SELECT

Querying Data

Retrieve exactly the required rows and columns with precise filters and ordering.

  • SELECT and aliases
  • WHERE and compound predicates
  • LIKE, IN and BETWEEN
  • Sorting, limiting and CASE
LEVEL 13Σ

Functions & Grouping

Summarize rows, form meaningful groups and filter aggregated results.

  • Scalar and aggregate functions
  • GROUP BY reasoning
  • WHERE versus HAVING
  • Conditional aggregation
LEVEL 14⋈

Joins & Set Operations

Combine related tables without losing rows or accidentally multiplying them.

  • Inner and outer joins
  • Cross and self joins
  • Join-condition debugging
  • UNION, INTERSECT and EXCEPT
LEVEL 15WITH

Subqueries & Advanced SQL

Solve multi-step analytical problems and explain why each query layer exists.

  • Scalar, table and correlated subqueries
  • EXISTS, ANY and ALL
  • CTEs and recursion
  • Window functions and ranking
PART 4 • LEVELS 16–18

Database Systems & Career Readiness

Connect SQL knowledge to performance, correctness, security and demonstrable project evidence.

LEVEL 16⚡

Views, Indexes & Optimization

Understand access paths and use query plans to improve slow SQL responsibly.

  • Views and materialized views
  • B+ tree and hash indexes
  • Sequential versus index scans
  • EXPLAIN and query optimization
LEVEL 17ACID

Transactions & Recovery

Keep concurrent changes correct and recoverable when operations fail.

  • ACID properties and schedules
  • Isolation anomalies
  • Locks, timestamps and deadlocks
  • Logging, checkpoints and recovery
LEVEL 18🛡️

Security, Projects & Placement

Protect database access, build portfolio evidence and explain decisions in interviews.

  • Roles, privileges and SQL injection
  • Backup and operational responsibility
  • Three guided capstone projects
  • Interview, viva and placement revision
