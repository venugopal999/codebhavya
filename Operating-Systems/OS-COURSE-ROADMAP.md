# CodeBhavya Operating Systems course roadmap

## Part 1 — Execution foundations

1. Operating System Foundations
2. Kernels & System Calls
3. Processes & PCB
4. Threads & Concurrency

## Part 2 — Resource control

5. CPU Scheduling
6. Process Synchronization
7. Deadlocks

## Part 3 — Memory and storage

8. Memory Management
9. Virtual Memory
10. File Systems
11. I/O & Disk Scheduling

## Part 4 — Systems and career readiness

12. Protection & Security
13. Linux & System Programming
14. Virtualization & Containers
15. Projects & Placement

Each level will combine detailed theory, visual state tracing, formative checks with misconception-specific feedback, exam questions and interview explanations. Later labs will include process-state simulation, scheduling Gantt charts, semaphore timelines, deadlock graphs, page replacement, address translation, file allocation and disk-head movement.
