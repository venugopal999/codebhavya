# Advanced Data Structures Concept Coverage Audit

The Advanced Data Structures library follows the existing CodeBhavya course
from Level 8 through Level 21. It contains 112 working C programs grouped into
14 compact level accordions.

| CodeBhavya level | Programs | Covered concepts |
| --- | ---: | --- |
| Level 8 — Performance Analysis | 8 | Linear, quadratic, logarithmic and n-log-n counting; binary-search comparisons; recursive-call growth; growth-rate comparison and amortized dynamic arrays |
| Level 9 — Disjoint Sets | 8 | Quick-find, quick-union, union by rank/size, path compression, component counting, connectivity queries and redundant-edge detection |
| Level 10 — Sparse Matrices | 8 | Triplet conversion/reconstruction, simple and fast transpose, sparse addition/multiplication, CSR storage and row aggregation |
| Level 11 — String Pattern Matching | 8 | Naive overlapping search, KMP prefix/search, Rabin–Karp, Z algorithm, Boyer–Moore bad-character rule, finite automata and Manacher's algorithm |
| Level 12 — Advanced Sorting | 8 | Stable counting, radix, Shell, comb, cycle, pancake, bitonic sorting and k-way merging |
| Level 13 — Advanced Searching | 8 | Lower/upper bounds, first/last occurrence, rotated search, peaks, exponential/interpolation search and binary search on answers |
| Level 14 — Balanced BST | 8 | AVL insertion/search/deletion/validation/rotations/order queries, left-leaning red–black trees and interval trees |
| Level 15 — Digital Search Trees | 8 | Trie search, prefix counts, deletion, autocomplete, longest common prefix, word break, bitwise tries and ternary search trees |
| Level 16 — Multiway Search Trees | 8 | B-tree node/path search, splitting, insertion/traversal, limits, 2–3 promotion, B+ leaf scans and capacity analysis |
| Level 17 — Advanced Heaps | 8 | D-ary, indexed, two-heap median, k-way list merging, binomial, leftist, pairing and Fibonacci-heap operations |
| Level 18 — Advanced Hashing | 8 | Quadratic probing, double hashing, cuckoo and Robin Hood hashing, Bloom filters, rehashing, universal hashing and LRU caching |
| Level 19 — File Organization | 8 | Fixed/variable records, random updates, sequential search, primary and inverted indexes, hashed files and free lists |
| Level 20 — Advanced Graphs | 8 | 0–1 BFS, DAG shortest paths, Johnson reweighting, Edmonds–Karp, Dinic, bipartite matching, Tarjan bridges and Eulerian circuits |
| Level 21 — Placement Structures | 8 | Fenwick trees, segment trees, lazy propagation, sparse tables, monotonic deques, top-k frequency, k-way streams and streaming medians |
| **Total** | **112** | **Complete CodeBhavya ADS level coverage** |

All ADS pages include canonical URLs, full source code, sample input/output,
algorithm notes, complexity, common-error guidance, a guided code tour and the
existing one-click compiler handoff.
