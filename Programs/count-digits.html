Count Digits in an Integer

Learn how to count digits in an integer using a clear C program.

count-digits.c
Open in compiler
#include <stdio.h>

int main(void)
{
    long long number, value;
    int count = 0;

    printf("Enter an integer: ");
    scanf("%lld", &number);
    value = number < 0 ? -number : number;
    do {
        count++;
        value /= 10;
    } while (value != 0);
    printf("Digit count = %d\n", count);
    return 0;
}

Algorithm and explanation

  1. Read the required input values.
  2. Repeatedly divide the absolute value by 10; a do-while correctly counts zero as one digit.
  3. Display the computed result.
