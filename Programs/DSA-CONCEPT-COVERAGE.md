# Data Structures Concept Coverage Audit

The Data Structures course contains 106 working C programs in eight compact
topic groups. This checklist is organized by concepts rather than an arbitrary
program-count target.

| Topic group | Programs | Covered concepts |
| --- | ---: | --- |
| Array Techniques | 12 | Prefix sums, difference arrays, Kadane's algorithm, fixed sliding windows, two pointers, Dutch national flag, Boyer-Moore majority vote, XOR missing number, reversal rotation, interval merging, inversion counting and next permutation |
| Singly Linked Lists | 14 | Creation, traversal, insertion at three positions, deletion at three positions, search, count, iterative and recursive reversal, middle node, nth node from end and Floyd cycle detection |
| Doubly & Circular Linked Lists | 8 | Bidirectional traversal, insertion, deletion, reversal, circular creation, circular insertion and circular deletion |
| Stacks & Expressions | 12 | Array and linked stacks, balanced delimiters, infix-to-postfix, postfix and prefix evaluation, string reversal, next greater element, stock span, two stacks in one array, minimum stack and recursive stack reversal |
| Queues & Deques | 10 | Linear, circular and linked queues, circular deque, priority queue, queue reversal, queue interleaving, binary-number generation, queue using stacks and stack using queues |
| Trees & Binary Search Trees | 20 | Recursive and iterative traversals, level order, height, node/leaf counts, sum, search, diameter, balance, mirroring, equality, LCA, BST insertion, search, deletion, min/max and validation |
| Heaps, Hashing & Disjoint Sets | 12 | Min/max heap operations, heap sort, kth largest, heap priority queue, open addressing, separate chaining, frequency hashing, union-find, cycle detection and Kruskal's MST |
| Graphs | 18 | Matrix/list representations, BFS, DFS, connected components, directed and undirected cycles, Kahn and DFS topological sorts, bipartite testing, unweighted shortest paths, Dijkstra, Bellman-Ford, Floyd-Warshall, Prim, transitive closure, articulation points and strongly connected components |
| **Total** | **106** | **Core linear, hierarchical, hashing and graph structures** |

Every definition supplies source code, sample input/output, algorithm notes,
time complexity and common mistakes. `validate-program-library.js` compiles and
executes all examples, including the entire 200-program C course.
