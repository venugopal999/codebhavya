Print Coordinate Pairs Using Nested Loops

Learn how to print coordinate pairs using nested loops using a clear C program.

#include <stdio.h>

int main(void)
{
    int rows, columns;
    printf("Enter rows and columns: ");
    scanf("%d %d", &rows, &columns);
    for (int row = 1; row <= rows; row++) {
        for (int column = 1; column <= columns; column++)
            printf("(%d,%d) ", row, column);
        putchar('\n');
    }
    return 0;
}

Algorithm and explanation
