even-or-odd.c
Copy & open compiler
#include <stdio.h>

int main(void)
{
    int number;
    printf("Enter an integer: " );
    scanf("%d", &number);
    if (number % 2 == 0)
        printf("%d is even.\n", number);
    else
        printf("%d is odd.\n", number);
    return 0;
}

PROGRAM EXPLANATION

Algorithm and explanation

  1. Read an integer.
  2. Calculate number % 2.
  3. If the remainder is zero, print even; otherwise print odd.

An even integer is exactly divisible by 2. Therefore number % 2 gives 0 for even values and a non-zero remainder for odd values.
