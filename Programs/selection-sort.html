Sort an Array Using Selection Sort

Learn how to sort an array using selection sort using a clear C program.

Code, copy and run

Open in compiler
#include <stdio.h>

int main(void)
{
    int size, values[100];

    scanf("%d", &size);
    if (size < 1 || size > 100) return 1;
    for (int index = 0; index < size; index++) scanf("%d", &values[index]);
    for (int start = 0; start < size - 1; start++) {
        int minimum = start;
        for (int index = start + 1; index < size; index++)
            if (values[index] < values[minimum]) minimum = index;
        int temporary = values[start]; values[start] = values[minimum]; values[minimum] = temporary;
    }
    for (int index = 0; index < size; index++) printf("%d%c", values[index], index == size - 1 ? '\n' : ' ');
    return 0;
}

PROGRAM EXPLANATION

Algorithm and explanation

  1. Read the required input values.
  2. Select the smallest remaining element and swap it into the next sorted position.
  3. Display the computed result.

Select the smallest remaining element and swap it into the next sorted position.
