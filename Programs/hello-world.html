PROGRAM EXPLANATION

Algorithm and explanation

  1. Start the main() function.
  2. Call printf() with the required message.
  3. Return 0 to finish successfully.

stdio.h declares printf(). Execution begins in main(), printf() writes the message, and return 0 reports successful completion.
