# C Concept Coverage Audit

This checklist prevents the program count from hiding gaps in the C syllabus.
The library now contains 200 programs and covers the following language areas.

| C concept family | Covered examples |
| --- | --- |
| Program structure and standard I/O | `main`, headers, `printf`, `scanf`, `fgets`, characters and data types |
| Operators and conversions | Arithmetic, remainder, bitwise operators, conditional operator, formulas and unit conversions |
| Decision making | Simple, nested and chained `if-else`, validation, grading and billing |
| `switch` statements | Calculator, weekdays, month days, vowels, grades, conversions, areas, banking and nested switch |
| Loop forms | Dedicated `for`, `while`, `do-while` and nested-loop examples |
| Jump statements | `break`, `continue`, `goto` and `return` |
| Number algorithms | Digits, prime, factors, factorial, Fibonacci, GCD, LCM and special numbers |
| Arrays | Traversal, insertion, deletion, rotation, frequency, duplicates, merging and order statistics |
| Searching and sorting | Linear/binary search; bubble, selection, insertion, quick and merge sort |
| Matrices | Arithmetic, transpose, diagonals, triangular, identity, symmetry and sparse matrices |
| Strings | Manual string operations, classification, frequency, words, anagrams and substring search |
| Functions | Parameters, return values, call by value, pointer-based reference and structure return |
| Recursion | Factorial, Fibonacci, power, GCD, string reversal, natural-number sum and binary search |
| Advanced functions | Variadic functions and function pointers |
| Preprocessor | Object/function-like macros and conditional compilation |
| Program entry | `argc` and `argv` command-line arguments |
| Storage duration | Static local variables |
| Pointers | Basic/double pointers, pointer arithmetic, structure pointers and arrays of pointers |
| Dynamic memory | `malloc`, `calloc`, `realloc`, dynamic arrays, dynamic matrices and `free` |
| User-defined types | Structures, nested structures, arrays of structures, `typedef`, unions and enums |
| Compact representation | Structure bit-fields |
| File handling | Text/binary files, append, copy, merge, compare, search, random access, rename and delete |

Linked lists, stacks, queues, trees, graphs and hashing belong to the separate
Data Structures program library, so they are not duplicated here.
