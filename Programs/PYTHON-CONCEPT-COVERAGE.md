# Python Program Library Coverage

The Python course contains 150 executable Python 3 programs in 15 compact topic
groups. Each group contains 10 programs and intentionally includes both core
syntax and concepts that learners commonly miss when moving beyond basics.

| Topic group | Programs | Important coverage |
| --- | ---: | --- |
| Basics & Input/Output | 10 | `print`, `input`, formatting, separators, escape sequences, comments and docstrings |
| Variables & Data Types | 10 | assignment, unpacking, conversion, complex, Boolean, `None`, bytes and constants |
| Operators & Numbers | 10 | arithmetic, floor division, modulus, comparison, logical, bitwise and numeric helpers |
| Decision Making | 10 | `if`, `elif`, nested decisions, conditional expressions, short circuit and `match` |
| Loops | 10 | `for`, `while`, nested loops, `break`, `continue`, loop `else`, `enumerate` and `zip` |
| Patterns & Number Problems | 10 | star/number patterns, factorial, Fibonacci, prime, Armstrong, palindrome, GCD and conversion |
| Strings | 10 | slicing, frequency, search, replacement, case conversion, splitting and joining |
| Lists | 10 | creation, mutation, slicing, comprehensions, filtering, sorting, flattening and copying |
| Tuples, Sets & Dictionaries | 10 | packing, unpacking, set algebra, dictionary access, update, iteration and comprehensions |
| Functions & Recursion | 10 | arguments, defaults, keywords, `*args`, `**kwargs`, lambda, recursion and annotations |
| Object-Oriented Programming | 10 | classes, constructors, methods, inheritance, overriding, `super`, properties and method types |
| Exceptions & Files | 10 | exception branches, raising/custom exceptions, text files, `pathlib`, context managers and `StringIO` |
| Modules, Dates & Regular Expressions | 10 | math, random, statistics, decimal, fractions, dates and regex operations |
| Functional & Advanced Python | 10 | map, filter, reduce, iterators, generators, decorators, closures, walrus and dataclasses |
| JSON, CSV & Collections | 10 | JSON, CSV, Counter, defaultdict, deque, namedtuple, ChainMap, heapq and bisect |
| **Total** | **150** | **Broad Python course and interview-practice coverage** |

All generated `.py` files pass `py_compile`, execute with Python 3, and produce
the expected sample output. Program pages use the same CodeBhavya page design,
guided line-by-line tour, copy/download actions, and one-click compiler handoff
as the existing C, DSA and ADS library.
