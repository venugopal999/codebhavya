# CodeBhavya Complete Core Java Course

This deployable `Java` folder contains an original 24-level course from the Java platform and basic syntax through object-oriented design, collections, streams, concurrency, JVM internals, JDBC, testing and placement projects. It also includes a 12-level Practice Arena with 36 original, verified Java 17 problems.

## Deployment

1. Copy the complete `Java` folder into the CodeBhavya repository root.
2. Keep the filenames unchanged.
3. Confirm the parent website contains `images/codebhavya-main-logo.png` and `images/codebhavya-icon-32.png`.
4. Open `Java/index.html` and test the roadmap.
5. Open `Java/lesson.html?level=1`, complete a quiz and verify progress.
6. Open `Java/practice.html`, reveal a hint, use the workspace and mark one problem solved.
7. Commit and push the folder to publish through GitHub Pages.

The course uses query-string lesson routes so one maintained lesson shell can present all 24 levels consistently. Course completion is stored locally under `codebhavya.java.course.progress.v1`; Practice Arena progress uses `codebhavya.java.practice.solved.v1`.
