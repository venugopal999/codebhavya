🔎Level 2 — Searching Challenges20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges progress from linear scanning to binary-search boundaries, rotated arrays, jump search, exponential search, ternary search, matrix lookup and binary search on an answer.

🫧Level 3 — Basic Sorting20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges develop bubble, selection and insertion sorting through ascending and descending order, pass tracing, operation counting, stable ordering and custom comparison rules.

⚡Level 4 — Efficient Sorting20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges apply merge sort, quick sort, quickselect and heap techniques to scalable ordering, inversion counting, stable records, top-K selection, nearly sorted data and interval merging.

🔗Level 5 — Linked List Missions20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges build pointer confidence through singly linked-list creation, insertion, deletion, search, reversal, middle and Kth-node logic, sorting, merging, doubly linked traversal, cycle detection and circular operations.

📚Level 6 — Stack Challenges20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges progress from push, pop and reversal to bracket validation, expression conversion and evaluation, monotonic-stack applications, recursive stack operations and placement-style problems.

🚶Level 7 — Queue Challenges20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges progress from standard and circular queue operations to deque windows, queue simulations, queue/stack conversions, priority queues and breadth-first search applications.

🌳Level 8 — Trees & Traversals20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges build binary trees from level-order data and explore DFS/BFS traversals, views, recursive properties, diameter, balance, LCA, boundary and vertical order, expression trees and maximum path sums.

⛰️Level 9 — BST & Binary Heap20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges apply binary-search-tree ordering to traversal, search, extrema, height, rank, predecessor/successor, LCA, range queries, validation, deletion and balanced construction before progressing to max-heaps, min-heaps, insertion, extraction, top-K selection and heap sort.

🕸️Level 10 — Graph Challenges20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These challenges progress through adjacency representation, degree analysis, BFS, DFS, connectivity, reachability, unweighted distances, cycle detection, bipartite graphs, topological ordering, directed reachability, grid graphs, multi-source BFS, Dijkstra, Kruskal and Bellman–Ford.

🧩Level 11 — Mixed DSA Systems20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These system-style challenges combine arrays, stacks, queues, deques, heaps, trees, graphs, disjoint sets and tries through undo/redo, round-robin scheduling, streaming statistics, cache simulation, dependency planning, connectivity queries, priority dispatch, Huffman merging and route reconstruction.

🏆Level 12 — Placement DSA Sprint20 newly written CodeBhavya challenges • five tests each
Open 20 Challenges

These placement-style challenges test optimized arrays, prefix hashing, Kadane's algorithm, prefix/suffix products, two pointers, monotonic stacks, sliding windows, interval scheduling, matrix traversal, linked-list reasoning, BST pair search, word-ladder BFS, disjoint sets, dynamic programming, backtracking and binary-search optimization.
