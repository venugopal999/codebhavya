🔎 Searching

Learn searching techniques from basic concepts to interview-oriented problems using C. Understand how different searching algorithms work and when to use each one.

01 • CONCEPT

📖 Concept Explanation

Searching is the process of finding a particular element, called a key, in a collection of elements.

Searching is one of the most important operations in Data Structures and is frequently asked in programming interviews.

Why is Searching Important?

  • Finding an element in an array
  • Searching records in databases
  • Finding values in sorted data
  • Searching in trees and graphs
  • Solving many interview problems efficiently

Searching Techniques Covered

  • Linear Search
  • Binary Search
  • Jump Search
  • Interpolation Search
  • Fibonacci Search
02 • UNDERSTAND

💡 Easy Examples

Example 1 — Linear Search

Consider the array:

10   25   30   45   60

Suppose we want to find 45.

We start from the first element and compare each element with 45.

10 ≠ 45
25 ≠ 45
30 ≠ 45
45 = 45 ✅

Therefore, 45 is found at index 3.

Example 2 — Binary Search

Binary Search works only when the array is sorted.

10   20   30   40   50   60   70

To find 60, Binary Search repeatedly divides the search range into two halves.

03 • ALGORITHMS

🔹 Searching Algorithms

1. Linear Search

  1. Start from the first element.
  2. Compare the current element with the key.
  3. If they are equal, return the position.
  4. Otherwise move to the next element.
  5. Continue until the element is found or the array ends.

2. Binary Search

  1. The array must be sorted.
  2. Find the middle element.
  3. If middle equals the key, return its position.
  4. If key is smaller, search the left half.
  5. If key is larger, search the right half.
  6. Repeat until the element is found.

3. Jump Search

  1. The array must be sorted.
  2. Jump ahead by a fixed block size.
  3. Identify the block where the element may exist.
  4. Perform a linear search inside that block.

4. Interpolation Search

Interpolation Search estimates the probable position of the key using the values at the beginning and end of the search range.

5. Fibonacci Search

Fibonacci Search divides the search range using Fibonacci numbers instead of directly using the middle position.

04 • PROGRAMMING

💻 C Programs

Program 1 — Linear Search 

#include <stdio.h>

int main()
{
    int n, key;
    int found = -1;

    scanf("%d", &n);

    int arr[n];

    for(int i = 0; i < n; i++)
    {
        scanf("%d", &arr[i]);
    }

    scanf("%d", &key);

    for(int i = 0; i < n; i++)
    {
        if(arr[i] == key)
        {
            found = i;
            break;
        }
    }

    if(found != -1)
        printf("Element found at index %d", found);
    else
        printf("Element not found");

    return 0;
}

Program 2 — Binary Search 

#include <stdio.h>

int main()
{
    int n, key;

    scanf("%d", &n);

    int arr[n];

    for(int i = 0; i < n; i++)
    {
        scanf("%d", &arr[i]);
    }

    scanf("%d", &key);

    int low = 0;
    int high = n - 1;

    while(low <= high)
    {
        int mid = low + (high - low) / 2;

        if(arr[mid] == key)
        {
            printf("Element found at index %d", mid);
            return 0;
        }

        if(arr[mid] < key)
            low = mid + 1;
        else
            high = mid - 1;
    }

    printf("Element not found");

    return 0;
}

Program 3 — Jump Search 

#include <stdio.h>
#include <math.h>

int main()
{
    int n, key;

    scanf("%d", &n);

    int arr[n];

    for(int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    scanf("%d", &key);

    int step = sqrt(n);
    int prev = 0;

    while(arr[(step < n ? step : n) - 1] < key)
    {
        prev = step;
        step += sqrt(n);

        if(prev >= n)
        {
            printf("Element not found");
            return 0;
        }
    }

    while(arr[prev] < key)
    {
        prev++;

        if(prev == step || prev == n)
        {
            printf("Element not found");
            return 0;
        }
    }

    if(arr[prev] == key)
        printf("Element found at index %d", prev);
    else
        printf("Element not found");

    return 0;
}

06 • COMPLEXITY

⚡ Time & Space Complexity

Algorithm Best Average Worst Space
Linear Search O(1) O(n) O(n) O(1)
Binary Search O(1) O(log n) O(log n) O(1)
Jump Search O(1) O(√n) O(√n) O(1)
Interpolation Search O(1) O(log log n) O(n) O(1)
Fibonacci Search O(1) O(log n) O(log n) O(1)
Interview Tip: Binary Search is one of the most important searching techniques because many advanced problems are based on the Binary Search idea.
07 • INTERVIEW

📝 Important Interview Points

  • Linear Search works on both sorted and unsorted arrays.
  • Binary Search requires sorted data.
  • Binary Search reduces the search space by half in every iteration.
  • Binary Search has O(log n) time complexity.
  • Jump Search requires sorted data.
  • Interpolation Search works particularly well when data is uniformly distributed.
  • Fibonacci Search uses Fibonacci numbers to divide the search range.
  • For an unsorted array, Linear Search is usually the simplest choice.

Common Interview Questions

  1. What is the difference between Linear Search and Binary Search?
  2. Why does Binary Search require a sorted array?
  3. What is the time complexity of Binary Search?
  4. How can Binary Search be implemented recursively?
  5. What is the difference between Jump Search and Binary Search?
  6. When should Interpolation Search be preferred?
  7. What happens if Binary Search is applied to an unsorted array?
08 • PRACTICE

🎯 Practice Problems

Problem 1 — Linear Search

Given an array of N integers and a key, find the index of the key using Linear Search.

Problem 2 — Binary Search

Given a sorted array, find whether a given element exists using Binary Search.

Problem 3 — First Occurrence

Given a sorted array containing duplicate elements, find the first occurrence of a key.

Problem 4 — Last Occurrence

Find the last occurrence of a given element in a sorted array.

Problem 5 — Count Occurrences

Find how many times a given element occurs in a sorted array.

Problem 6 — Search Insert Position

Find the position where a given value should be inserted into a sorted array.

Problem 7 — Search in Rotated Array

Search for an element in a sorted array that has been rotated.

Problem 8 — Square Root using Binary Search

Find the integer square root of a number using Binary Search.
