🔍 Searching

Learn searching techniques from the basics to interview-level problems using C.

📚 What is Searching?

Searching is the process of finding a particular element, called a key, inside a collection of data.

Searching is one of the most frequently used operations in programming and is an important concept for technical interviews.

💡 Important: The efficiency of a searching algorithm depends mainly on how the data is organized. For example, Binary Search requires the data to be sorted.

1. Linear Search

Linear Search checks every element one by one until the required element is found.

How it works

  1. Start from the first element.
  2. Compare the element with the key.
  3. If they are equal, return the position.
  4. Otherwise move to the next element.
  5. If the entire array is checked, the element is not present.
Example:

Array: 10 25 30 45 50

Search key: 45

The algorithm checks: 10 → 25 → 30 → 45

45 found at index 3.

C Program 

#include <stdio.h>

int main() {

    int n, key;
    int found = -1;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    scanf("%d", &key);

    for (int i = 0; i < n; i++) {

        if (arr[i] == key) {
            found = i;
            break;
        }

    }

    if (found != -1)
        printf("Element found at index %d", found);
    else
        printf("Element not found");

    return 0;
}

Complexity

Case Time Complexity
Best Case O(1)
Average Case O(n)
Worst Case O(n)
Space O(1)

2. Binary Search

Binary Search is an efficient searching algorithm that repeatedly divides a sorted array into two halves.

⚠️ Important: Binary Search works correctly only when the array is sorted according to the search condition.

Basic Idea

Instead of checking every element, Binary Search checks the middle element.

  • If key == arr[mid], the element is found.
  • If key < arr[mid], search the left half.
  • If key > arr[mid], search the right half.

C Program — Iterative Binary Search 

#include <stdio.h>

int binarySearch(int arr[], int n, int key) {

    int low = 0;
    int high = n - 1;

    while (low <= high) {

        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
            return mid;

        if (key < arr[mid])
            high = mid - 1;
        else
            low = mid + 1;
    }

    return -1;
}

int main() {

    int n, key;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    scanf("%d", &key);

    int result = binarySearch(arr, n, key);

    if (result != -1)
        printf("Element found at index %d", result);
    else
        printf("Element not found");

    return 0;
}

Complexity

Time Complexity: O(log n)
Space Complexity: O(1)

3. Recursive Binary Search

Binary Search can also be implemented using recursion. The search range is reduced after every recursive call. 

#include <stdio.h>

int binarySearch(int arr[], int low, int high, int key) {

    if (low > high)
        return -1;

    int mid = low + (high - low) / 2;

    if (arr[mid] == key)
        return mid;

    if (key < arr[mid])
        return binarySearch(arr, low, mid - 1, key);

    return binarySearch(arr, mid + 1, high, key);
}

int main() {

    int arr[] = {10, 20, 30, 40, 50, 60};

    int n = sizeof(arr) / sizeof(arr[0]);

    int key = 40;

    int result =
        binarySearch(arr, 0, n - 1, key);

    printf("%d", result);

    return 0;
}
Interview Tip: Use low + (high - low) / 2 instead of (low + high) / 2 to avoid integer overflow in languages where integer overflow is a concern.

4. First Occurrence of an Element

When duplicate elements are present, normal Binary Search may return any occurrence.

To find the first occurrence, continue searching toward the left even after finding the key. 

int firstOccurrence(int arr[], int n, int key) {

    int low = 0;
    int high = n - 1;
    int answer = -1;

    while (low <= high) {

        int mid = low + (high - low) / 2;

        if (arr[mid] == key) {

            answer = mid;
            high = mid - 1;

        }
        else if (arr[mid] < key) {

            low = mid + 1;

        }
        else {

            high = mid - 1;

        }
    }

    return answer;
}

5. Last Occurrence of an Element

To find the last occurrence, continue searching toward the right after finding the key. 

int lastOccurrence(int arr[], int n, int key) {

    int low = 0;
    int high = n - 1;
    int answer = -1;

    while (low <= high) {

        int mid = low + (high - low) / 2;

        if (arr[mid] == key) {

            answer = mid;
            low = mid + 1;

        }
        else if (arr[mid] < key) {

            low = mid + 1;

        }
        else {

            high = mid - 1;

        }
    }

    return answer;
}

6. Count Occurrences

In a sorted array, the number of occurrences of an element can be found efficiently using its first and last positions.

Count = Last Position − First Position + 1
Example:

Array: 1 2 2 2 3 4

First occurrence of 2 = index 1

Last occurrence of 2 = index 3

Count = 3 − 1 + 1 = 3

7. Search in a Rotated Sorted Array

A sorted array can be rotated around a pivot. For example:

1 2 3 4 5 6 7
↓ rotation
4 5 6 7 1 2 3

We can still perform searching in O(log n) by determining which half of the array is sorted.

C Implementation 

int searchRotated(int arr[], int n, int key) {

    int low = 0;
    int high = n - 1;

    while (low <= high) {

        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
            return mid;

        /* Left half is sorted */

        if (arr[low] <= arr[mid]) {

            if (arr[low] <= key &&
                key < arr[mid]) {

                high = mid - 1;

            } else {

                low = mid + 1;

            }

        }

        /* Right half is sorted */

        else {

            if (arr[mid] < key &&
                key <= arr[high]) {

                low = mid + 1;

            } else {

                high = mid - 1;

            }
        }
    }

    return -1;
}

9. Binary Search on Answer

One of the most important interview techniques is using Binary Search not directly on an array, but on a possible range of answers.

This technique is commonly called Binary Search on Answer.

💡 Recognize the pattern: If the answer lies in a range and you can determine whether a particular answer is possible, Binary Search may be applicable.

Common Examples

  • Minimum capacity problems
  • Minimum maximum distance
  • Allocate books
  • Painter partition problems
  • Aggressive cows

🏆 Interview Tips

Tip 1: Always check whether the array is sorted before choosing Binary Search.
Tip 2: Be careful with the boundary conditions: low, high and mid.
Tip 3: Learn the difference between finding any occurrence, first occurrence and last occurrence.
Tip 4: Many difficult interview problems are actually Binary Search problems disguised as optimization problems.
