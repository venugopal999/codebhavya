🔎 Searching

SEARCHING FUNDAMENTALS

📖 What is Searching?

Searching is the process of finding a particular element, called a target, in a collection of data.

The collection may be an array, linked list, tree or another data structure.

💡 Important: The searching technique we choose depends on the data structure and whether the data is sorted or unsorted.

Common Searching Techniques

  • Linear Search
  • Binary Search
  • Interpolation Search
  • Jump Search
  • Fibonacci Search
  • Linked List Searching
SEARCHING TECHNIQUE 01

🔹 Linear Search

📖 Concept Explanation

Linear Search checks each element one by one from the beginning until the target element is found or the collection ends.

💡 Key Idea: Check elements sequentially from left to right.

🔹 Step-by-Step Algorithm

  1. Start from the first element.
  2. Compare the current element with the target.
  3. If they are equal, return the position.
  4. Otherwise move to the next element.
  5. Repeat until the element is found.
  6. If the array ends, report that the element is not present.

💡 Example

Consider: 

10  25  37  45  60

Search for 45. 

10 ≠ 45
25 ≠ 45
37 ≠ 45
45 = 45 ✓

Therefore, 45 is found at position 4.

💻 C Program 

#include <stdio.h>

int main()
{
    int n, key;
    int found = -1;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++)
    {
        scanf("%d", &arr[i]);
    }

    scanf("%d", &key);

    for (int i = 0; i < n; i++)
    {
        if (arr[i] == key)
        {
            found = i;
            break;
        }
    }

    if (found != -1)
        printf("Element found at position %d\n", found + 1);
    else
        printf("Element not found\n");

    return 0;
}

📥 Input 

5
10 25 37 45 60
45

🖥️ Output 

Element found at position 4

⚡ Complexity

Case Complexity Why?
Best O(1) The target is the first element. Only one comparison is required.
Average O(n) The target may occur somewhere in the middle, requiring several comparisons.
Worst O(n) The target is the last element or does not exist, so every element is checked.

Space Complexity: O(1)

Only a constant amount of extra memory is used.

📌 Important Points

  • Works on both sorted and unsorted data.
  • Simple and easy to implement.
  • No preprocessing is required.
  • Not efficient for very large datasets.
SEARCHING TECHNIQUE 02

🔹 Binary Search

📖 Concept Explanation

Binary Search repeatedly divides a sorted array into two halves and determines which half may contain the target.

⚠️ Important: Binary Search requires the data to be sorted.

💡 Key Idea

Compare the target with the middle element.

  • If equal → element found.
  • If target is smaller → search left half.
  • If target is larger → search right half.

🔹 Approach 1 — Iterative Binary Search

The iterative approach uses a loop to repeatedly reduce the search range.

🔹 Step-by-Step Algorithm

  1. Set low = 0.
  2. Set high = n - 1.
  3. Calculate the middle position.
  4. Compare the middle element with the target.
  5. Adjust the search range.
  6. Repeat until the target is found or the range becomes empty.

💡 Example 

Array:
10  20  30  40  50  60  70

Target = 60

Middle = 40

60 > 40
→ Search right half

Middle = 60
→ Found ✓

💻 C Program — Iterative 

#include <stdio.h>

int main()
{
    int n, key;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    scanf("%d", &key);

    int low = 0;
    int high = n - 1;
    int found = -1;

    while (low <= high)
    {
        int mid = low + (high - low) / 2;

        if (arr[mid] == key)
        {
            found = mid;
            break;
        }
        else if (arr[mid] < key)
        {
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    if (found != -1)
        printf("Element found at position %d\n", found + 1);
    else
        printf("Element not found\n");

    return 0;
}

⚡ Iterative Complexity

Case Complexity Reason
Best O(1) Target is the middle element in the first comparison.
Average O(log n) The search space is approximately halved each time.
Worst O(log n) The algorithm continues until the search range becomes empty.

Space Complexity: O(1)

🔹 Approach 2 — Recursive Binary Search

In the recursive approach, the function calls itself on the appropriate half of the array.

🔹 Step-by-Step Algorithm

  1. Find the middle element.
  2. If it matches the target, return its position.
  3. If target is smaller, recursively search the left half.
  4. If target is larger, recursively search the right half.
  5. Stop when the search range becomes invalid.

💻 C Program — Recursive 

#include <stdio.h>

int binarySearch(int arr[], int low, int high, int key)
{
    if (low > high)
        return -1;

    int mid = low + (high - low) / 2;

    if (arr[mid] == key)
        return mid;

    if (arr[mid] > key)
        return binarySearch(arr, low, mid - 1, key);

    return binarySearch(arr, mid + 1, high, key);
}

int main()
{
    int n, key;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    scanf("%d", &key);

    int result = binarySearch(arr, 0, n - 1, key);

    if (result != -1)
        printf("Element found at position %d\n", result + 1);
    else
        printf("Element not found\n");

    return 0;
}

⚡ Recursive Complexity

Time Complexity: O(log n)

The search space is divided approximately in half during every recursive call.

Space Complexity: O(log n)

Recursive function calls are stored in the call stack. There can be approximately log n recursive calls.

💡 Interview Tip: Iterative Binary Search uses O(1) auxiliary space, while recursive Binary Search requires O(log n) stack space.
SEARCHING TECHNIQUE 03

🔹 Interpolation Search

📖 Concept Explanation

Interpolation Search is an improvement over Binary Search for uniformly distributed sorted data.

Instead of always selecting the middle position, it estimates where the target is likely to be located.

💡 Key Idea: Binary Search asks: "What is in the middle?"

Interpolation Search asks: "Where is the target likely to be?"

🔹 Position Formula

pos = low + ((key - arr[low]) × (high - low)) / (arr[high] - arr[low])

🔹 When is it useful?

  • Data must be sorted.
  • Values should be approximately uniformly distributed.
  • Works especially well when values are evenly spread.

⚡ Complexity

  • Best: O(1)
  • Average: O(log log n) for uniformly distributed data
  • Worst: O(n)
  • Space: O(1)

💻 C Program 

#include <stdio.h>

int main()
{
    int n, key;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    scanf("%d", &key);

    int low = 0;
    int high = n - 1;
    int found = -1;

    while (low <= high &&
           key >= arr[low] &&
           key <= arr[high])
    {
        if (arr[high] == arr[low])
        {
            if (arr[low] == key)
                found = low;

            break;
        }

        int pos = low +
            ((key - arr[low]) * (high - low)) /
            (arr[high] - arr[low]);

        if (arr[pos] == key)
        {
            found = pos;
            break;
        }

        if (arr[pos] < key)
            low = pos + 1;
        else
            high = pos - 1;
    }

    if (found != -1)
        printf("Element found at position %d\n", found + 1);
    else
        printf("Element not found\n");

    return 0;
}
SEARCHING TECHNIQUE 04

🔹 Jump Search

📖 Concept Explanation

Jump Search works on a sorted array by jumping ahead by fixed block sizes and then performing a linear search inside the relevant block.

💡 Key Idea

Instead of checking every element, skip several elements at a time and then search the selected block.

🔹 Optimal Jump Size

√n

🔹 Step-by-Step Algorithm

  1. Calculate the jump size as √n.
  2. Jump through the array block by block.
  3. Stop when the block may contain the target.
  4. Perform Linear Search inside that block.
  5. Return the position if found.

💻 C Program 

#include <stdio.h>
#include <math.h>

int main()
{
    int n, key;

    scanf("%d", &n);

    int arr[n];

    for (int i = 0; i < n; i++)
        scanf("%d", &arr[i]);

    scanf("%d", &key);

    int jump = (int)sqrt(n);
    int left = 0;
    int right = jump;
    int found = -1;

    while (left < n && arr[(right < n ? right : n) - 1] < key)
    {
        left = right;
        right += jump;

        if (left >= n)
            break;
    }

    if (left < n)
    {
        int end = right < n ? right : n;

        for (int i = left; i < end; i++)
        {
            if (arr[i] == key)
            {
                found = i;
                break;
            }
        }
    }

    if (found != -1)
        printf("Element found at position %d\n", found + 1);
    else
        printf("Element not found\n");

    return 0;
}

⚡ Complexity

  • Best: O(1)
  • Average: O(√n)
  • Worst: O(√n)
  • Space: O(1)
SEARCHING TECHNIQUE 05

🔹 Fibonacci Search

📖 Concept Explanation

Fibonacci Search searches a sorted array by using Fibonacci numbers to divide the search range.

💡 Key Idea

Instead of dividing the array exactly in half, Fibonacci Search uses Fibonacci numbers to determine comparison positions.

⚡ Complexity

  • Best: O(1)
  • Average: O(log n)
  • Worst: O(log n)
  • Space: O(1)
📌 Interview Note: Fibonacci Search is mainly important for understanding alternative searching strategies. Binary Search is generally more common in practical coding interviews.
SEARCHING IN DATA STRUCTURES

🔗 Searching in a Linked List

📖 Concept Explanation

Searching in a linked list is normally performed using Linear Search because linked-list nodes are not directly accessible by index.

💡 Key Idea

Start from the head and move through each node until the target is found or the list ends.

⚡ Complexity

Best Case: O(1) — target is in the first node.

Worst Case: O(n) — target is in the last node or absent.

Space: O(1) for iterative searching.

IMPORTANT SEARCHING PATTERNS

🔹 Important Search Variations

1. First Occurrence

Find the first position where a target occurs in a sorted array containing duplicates.

2. Last Occurrence

Find the last position where the target occurs.

3. Count Occurrences

Count how many times a target appears in a sorted array.

4. Search in Rotated Sorted Array

Search efficiently when a sorted array has been rotated around a pivot.

5. Find Peak Element

Use Binary Search principles to find an element that is greater than its neighbouring elements.

6. Binary Search on Answer

Apply Binary Search to a range of possible answers instead of directly searching an array.

INTERVIEW & PRACTICE

📝 Important Interview Points

  • Linear Search works on unsorted data.
  • Binary Search requires sorted data.
  • Binary Search reduces the search space by half.
  • Iterative Binary Search uses O(1) auxiliary space.
  • Recursive Binary Search uses O(log n) stack space.
  • Interpolation Search works best on uniformly distributed data.
  • Jump Search requires sorted data.
  • Linked Lists generally use sequential searching.

💡 Interview Tips

  • Always check whether the input is sorted.
  • Remember the difference between O(n) and O(log n).
  • Know both iterative and recursive Binary Search.
  • Be careful with duplicate elements.
  • Use mid = low + (high - low) / 2 to avoid integer overflow.

Problem 4 — Last Occurrence

Find the last occurrence of a target in a sorted array.

When the target is found, continue searching toward the right.
Store the current position and set low = mid + 1.

Problem 5 — Count Occurrences

Count the number of times a target occurs in a sorted array.

Find the first and last occurrence.
Count = last occurrence - first occurrence + 1.

Use Binary Search and track the lower bound.

Problem 7 — Search in Rotated Array

At least one half of the array is always sorted.
Identify the sorted half and determine whether the target lies inside it.

Problem 8 — Find Peak Element

Find an element greater than its neighbours.

Compare the middle element with the next element.
If arr[mid] < arr[mid + 1], move right; otherwise move left.

Problem 9 — Square Root using Binary Search

Find the integer square root of a number.

Search between 1 and n.
Binary search for the largest mid such that mid × mid is less than or equal to n.

Problem 10 — Missing Element

Find a missing element from a sorted sequence.

Compare the actual index with the expected value.
Use Binary Search to locate the first index where arr[i] differs from the expected value.

Problem 11 — Lower Bound

When condition is satisfied, continue searching left.

Problem 12 — Upper Bound

Find the first position where an element is greater than the target.

Search for the first value strictly greater than key.
If arr[mid] > key, store mid and search left.

Problem 13 — Interpolation Search

Implement Interpolation Search for uniformly distributed sorted data.

Use the interpolation position formula.

Problem 14 — Jump Search

Implement Jump Search on a sorted array.

Use √n as the jump size.

Problem 15 — Fibonacci Search

Generate Fibonacci numbers until one is greater than or equal to the array size.

Problem 16 — Search in Linked List

Start from head and move through next pointers.
Traverse until current becomes NULL or current->data equals the target.

Problem 17 — First Greater Element

Find the first element greater than a given key in a sorted array.

This is closely related to Upper Bound.
Use Binary Search and search for the first element strictly greater than key.

Problem 18 — First Smaller Element

Find the last element smaller than a given key.

When arr[mid] is smaller, store it and search right.
Maintain the best candidate while performing Binary Search.

Problem 19 — Minimum in Rotated Array

Find the minimum element in a rotated sorted array.

Compare the middle element with the rightmost element.
If arr[mid] is greater than arr[high], search right; otherwise search left including mid.

Problem 20 — Binary Search on Answer

Apply Binary Search to the answer space rather than directly to an array.
